## 學習目標

- 把一句「我們發現」拆成宣傳單上的大數字、標題和提醒
- 把百分比換成好懂的說法，例如40%換成「每5人就有2人」
- 用Canva排出主次分明的版面：先看到數字，再看到提醒，最後才是圖表和出處
- 知道Canva素材和AI生成圖片可以怎麼用、要怎麼標示

## 一、3秒測試

老師會投影兩張宣傳單，每張只停**3秒**。看完回答：哪一張你記得它在說什麼？

- <a href="../../materials/flyer/flyer-sample-a.jpg" target="_blank" rel="noopener">宣傳單A</a>
- <a href="../../materials/flyer/flyer-sample-b.jpg" target="_blank" rel="noopener">宣傳單B</a>

兩張用的是同一個示範題目，說明在下一節。

宣傳單貼在走廊、公布欄上，大家通常是走過去時看一眼，不會停下來慢慢讀。所以宣傳單要做到：**3秒內看得出它在提醒什麼**。

## 二、從句子到宣傳單

第十週每個人都寫了一句「我們發現」。這句話很完整，但太長了，直接放上宣傳單沒有人會讀完。要先把它拆開。

下面用一個示範題目來說明。這一題**不是任何一組的題目**，是老師用第四週學過的「雙重驗證」另外出的：

> 你的帳號（遊戲、社群、LINE等），有沒有任何一個開啟了雙重驗證（登入時除了密碼，還要輸入簡訊驗證碼）？

假設一個20人的班級，有8個人回答「一個都沒有」，就是40%。**這個「我們班40%」是老師虛構的**，只是為了示範。

比較對象則是**真實的調查**：台灣找不到國中生開雙重驗證的調查，所以用<a href="https://www.cbs.nl/en-gb/news/2025/51/three-quarters-of-internet-users-choose-two-step-verification" target="_blank" rel="noopener">荷蘭統計局2024年的網路安全調查</a>。荷蘭15～24歲的網路使用者中，有20.1%所有帳號都沒有開雙重驗證。

寫成第十週的「我們發現」：

> 我們班有40%的人所有帳號都沒有開雙重驗證，比荷蘭15～24歲調查的20.1%高19.9個百分點，所以只要密碼外洩，這些人的帳號別人都能直接登入。
> 不過，這份調查是在荷蘭做的，對象是15～24歲，跟我們不一樣。

找不到台灣的調查、改用國外的資料，是做資料分析時常有的事。這時候一定要寫清楚是哪個國家、哪個年齡，不能寫成「全國調查」。

拆成宣傳單上的區塊。下表的順序，就是範本上由上到下的位置：

| 範本上的區塊 | 要寫什麼 | 老師範例怎麼寫 |
| --- | --- | --- |
| **標籤**（左上角） | 你們組的主題＋班級、組別、姓名 | 資訊安全宣導｜老師示範 |
| **大標題**（兩行） | 一句問句，讓人想看下去 | 密碼被偷了，帳號還只有你在用嗎？ |
| **大數字**（全張最大） | 「我們班有○%」換成好懂的說法 | 每5人就有2人 |
| **說明**（大數字下面） | 這個數字在說什麼事 | 所有帳號都沒開雙重驗證 |
| **圖表＋差距** | 第十週做的柱狀圖，下面寫差幾個百分點 | 我們班 vs 荷蘭調查，比荷蘭高19.9個百分點 |
| **為什麼危險？** | 三個可能發生的危險，每點兩行以內 | 密碼一外洩，別人馬上就能登入 |
| **提醒**（粉紅色塊） | 「所以」後面想讓大家做的事，10個字以內；下面一行寫具體怎麼做 | 現在就開啟雙重驗證！ |
| **資料來源**（最下面） | 我們班的人數、比較資料的名稱 | 本班問卷（20人）、荷蘭統計局2024網路安全調查（15～24歲） |

範本上寫「比較對象」的地方，要換成**你們組真正比較的對象**：有全國數字的寫調查名稱（例如「全國調查」），比的是全年級的就寫「全年級」。「高／低」留下對的那一個。

範本的提醒色塊寫著「最好有CTA」。CTA是英文「Call To Action」的縮寫，意思是「呼籲大家採取行動」：提醒要叫大家**去做一件事**，例如「現在就開啟雙重驗證！」，而不是只說「很危險」。

### 百分比換說法

「40%」要想一下才知道有多少，「每5人就有2人」一看就懂。找最接近的說法：

| 比例 | 換成 |
| --- | --- |
| 大約50% | 每2人就有1人 |
| 大約33% | 每3人就有1人 |
| 大約25% | 每4人就有1人 |
| 大約20% | 每5人就有1人 |
| 大約40% | 每5人就有2人 |
| 大約10% | 每10人就有1人 |
| 大約67% | 每3人就有2人 |
| 大約75% | 每4人就有3人 |

換說法時，**要選最接近的，不能為了嚇人而誇大**。例如27%比較接近「每4人就有1人」，不能寫成「每3人就有1人」。這跟第十週圖表的縱軸要從0開始是同一個道理：數字要誠實。

如果你選的是Q3（平均分數），大數字可以直接寫分數，例如「4.2分／滿分5分」，標題寫清楚這個分數在問什麼。

### 提醒不是把數字再說一次

| ✗ 只把數字再說一次 | ✓ 告訴大家要做什麼 |
| --- | --- |
| 40%的人沒開雙重驗證 | 現在就開啟雙重驗證 |
| 很多人公開生日 | 生日不要當密碼 |
| 大家都收過可疑連結 | 奇怪的連結，先別點 |

動手之前，先在紙上或資料筆記的旁邊，把你的五個區塊寫出來。

## 三、排版的七個重點

內容想好了，接下來要決定「放在哪裡、放多大」。同樣的內容，排法不一樣，別人記不記得住就差很多。動手之前先看一次，做完再用這七點檢查。

1. **只有一個主角**<span class="explain">先決定別人第一眼要看到什麼，通常是大數字。其他東西都要比它小。如果每樣東西都放很大，就等於每樣都在搶第一眼，反而什麼都看不到。</span>
2. **大小差距要拉開**<span class="explain">大數字、標題、說明文字至少分成三種大小，而且一眼就看得出差別。大小差不多，就分不出誰比較重要。</span>
3. **照眼睛移動的順序排**<span class="explain">看傳單時，眼睛通常從左上開始，往右，再往左下，最後到右下，像一個「Z」字。所以最重要的放在上面，提醒放在最後面（最下面），讓人看完數字，最後記住要做什麼。</span>
4. **提醒要獨立出來**<span class="explain">提醒不要混在一堆字中間，用一個色塊、外框或空白把它圈出來，放在版面下方。</span>
5. **重點靠對比，不是靠更多顏色**<span class="explain">選一個最醒目的顏色當「強調色」，只用在最重要的東西（例如大數字、我們班的柱子）。顏色最多3種、字體最多2種，用太多反而每個都不明顯。字和背景的顏色要差很多，例如深色底配白字、淺色底配深色字。</span>
6. **有關的放一起，邊緣要對齊**<span class="explain">圖表和它的說明放在一起；資料來源、班級組別放在一起。所有東西的邊緣對齊同一條線，拖曳時出現的紫色線就是Canva的對齊線。看起來亂，通常不是顏色的問題，而是沒有對齊。</span>
7. **留白**<span class="explain">四周和每一塊之間都要留一點空白。如果排完還是很擠，代表內容太多，要刪內容，不是把字縮小、把空白擠掉。</span>

**最後檢查：** 把Canva畫面縮小（右下角的百分比調到30%左右），或站起來離螢幕遠一點看。這樣還看得出重點是什麼、誰比較重要，就排好了。

這七個重點整理自<a href="https://www.pongo.com.tw/flyer-layout-design/" target="_blank" rel="noopener">〈傳單版面設計原則〉</a>（龐果設計），想多了解可以去看原文。

## 四、登入Canva

1. 打開你的**學校Email**，找到老師寄的「**加入Canva班級**」邀請信，點信裡的連結加入班級
2. 選「**以Google帳號繼續**」，用**學校的Google帳號**登入
3. 打開<a href="https://canva.link/t8v9dfm4yxgb7ct" target="_blank" rel="noopener">宣傳單範本</a>。這份是老師的檔案，**只能看、不能改**
4. 點左上角的「**檔案**」→「**建立副本**」，Canva會幫你建立一份**自己的副本**，之後都在這份副本上做
5. 點左上角的檔名，改成「**W12宣傳單_<span data-class-code>7XX</span>_座號_姓名**」

範本有兩頁：**第1頁是空白範本**，你要在這一頁上做；**第2頁是老師範例**，做的時候可以對照。老師範例已經鎖住、也已經設成隱藏，別人打開你分享的連結時不會看到這一頁，所以**不用動它，也不用刪掉**。

範本上已經排好每個區塊的位置，你要做的是換成自己的內容，再調整成你喜歡的樣子。

## 五、動手做

照下面的順序做，**先把內容放齊，最後再調顏色和字體**。

### 第一步：換文字

點範本上的文字框兩下，照第二節的表，把每個區塊換成你自己的內容。有方括號 [ ] 和「X」的地方都要換掉，方括號也要刪掉。

- 文字太長擠不下時，先試著刪字，不要直接把字縮小
- 大數字一定要是全張最大的字

### 第二步：放圖表

選一種做法：

**做法一：用第十週的圖表（比較快）**

1. 打開你的試算表，切到「**比較表**」分頁
2. 點你選的那張圖表，按右上角的「**⋮**」→「**下載**」→「**PNG 圖片 (.png)**」
3. 回到Canva，點左邊的「**上傳**」→「**上傳檔案**」，選剛剛下載的圖片
4. 上傳完成後，點一下圖片就會放進宣傳單，拖到範本的圖表位置

**做法二：在Canva重做一張（可以自己配色）**

1. 點左邊的「**元素**」，往下找到「**圖表**」，選「**長條圖**」
2. 右邊會出現表格，把「我們班」和比較對象的數字填進去（例如 40 和 20.1）
3. 點其中一根柱子，可以改顏色。把「**我們班**」那根改成最醒目的顏色，比較對象用灰色，讓人一眼看到重點

不管用哪一種，**圖表上的數字都要跟第十週的比較表一樣**。

### 第三步：換插圖

範本右上角的手機和盾牌是老師範例用的，要換成**符合你們組主題**的插圖：點一下原本的插圖按 `Delete` 刪掉，再點左邊的「**元素**」，用關鍵字搜尋，例如「密碼」、「手機」、「鎖」、「相機」、「著作權」。

- 只能用**Canva素材庫裡的**圖片和圖示，不要從Google圖片下載別人的圖。這就是第五週學的合理使用：網路上的圖片大多有著作權，不能直接拿來用
- 如果你用Canva的AI功能生成圖片，要在圖片旁邊用小字標示「**AI生成**」，讓看的人知道這不是你畫的
- 圖片是配角，不能比大數字還搶眼

### 第四步：調整版面

內容都放好之後，照第三節的七個重點一項一項調整：主角夠不夠大、大小有沒有拉開、提醒有沒有獨立出來、顏色和字體有沒有太多、有沒有對齊、有沒有留白。最後把畫面縮小看一次。

## 六、自我檢查

做完先自己檢查一次：

- [ ] 範本上方括號 [ ] 和「X」的地方都換成自己的內容，插圖和圖表也換成自己的
- [ ] 大數字是全張最大的字，而且跟比較表上的一樣
- [ ] 提醒是告訴大家要做什麼，不是把數字再說一次
- [ ] 有圖表，看得出我們班和比較對象誰比較高
- [ ] 「為什麼危險？」寫了三點
- [ ] 最下面有資料來源
- [ ] 圖片來自Canva素材庫；用AI生成的有標示「AI生成」
- [ ] 字體不超過2種、顏色不超過3種
- [ ] 東西都有對齊，四周有留白

再跟隔壁同學交換螢幕，讓對方看你的宣傳單**3秒**，然後問他：「這張在提醒什麼？」對方答得出來，就過關了；答不出來，回去把最重要的字放大、把不重要的刪掉。

## 七、繳交

1. 在Canva右上角點「**分享**」
2. 「協作連結」改成「**知道連結的任何人**」，權限選「**可檢視**」
3. 點「**複製連結**」
4. 打開下方的「**第十二週繳交表單**」，貼上連結，再填你的大數字和提醒

**今天的課堂作業：** 宣傳單做完並通過自我檢查，繳交表單送出。宣傳單會和之後的四格漫畫、成果發表一起算進段考3的成績，老師會照第六節的檢查表評分。
