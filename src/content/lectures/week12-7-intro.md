## 學習目標

- 把一句「我們發現」拆成宣傳單上的大數字、標題和提醒
- 把百分比換成好懂的說法，例如35%換成「每3人就有1人」
- 用Canva排出主次分明的版面：先看到數字，再看到提醒，最後才是圖表和出處
- 知道Canva素材和AI生成圖片可以怎麼用、要怎麼標示

## 一、3秒測試

老師會投影兩張宣傳單，每張只停**3秒**。看完回答：哪一張你記得它在說什麼？

- <a href="PLACEHOLDER_SAMPLE_A_URL" target="_blank" rel="noopener">宣傳單A</a>
- <a href="PLACEHOLDER_SAMPLE_B_URL" target="_blank" rel="noopener">宣傳單B</a>

宣傳單貼在走廊、公布欄上，大家通常是走過去時看一眼，不會停下來慢慢讀。所以宣傳單要做到：**3秒內看得出它在提醒什麼**。

## 二、從句子到宣傳單

第十週每個人都寫了一句「我們發現」。這句話很完整，但太長了，直接放上宣傳單沒有人會讀完。要先把它拆開。

用第十週講義的範例（題目和數字都是虛構的）：

> 我們班有35%的人跟朋友共用同一組遊戲帳號密碼，比全國調查的25%高10個百分點，所以共用帳號密碼在我們班比想像中常見，大約每3個人就有1個。

拆成宣傳單上的五個區塊：

| 區塊 | 從句子的哪裡來 | 範例 | 大小 |
| --- | --- | --- | --- |
| **大數字** | 「我們班有○%」，換成好懂的說法 | 每3人就有1人 | 最大 |
| **標題** | 這個數字在說什麼事 | 跟朋友共用遊戲密碼 | 第二大 |
| **提醒** | 「所以」後面想讓大家做的事，縮成10個字以內 | 帳號密碼，只給自己 | 第二大 |
| **圖表** | 第十週做的柱狀圖 | 我們班 vs 全國 | 中等 |
| **資料來源** | 比較表用的資料 | 資料來源：本班問卷（20人）、兒福聯盟2023 | 最小，放最下面 |

### 百分比換說法

「35%」要想一下才知道有多少，「每3人就有1人」一看就懂。找最接近的說法：

| 比例 | 換成 |
| --- | --- |
| 大約50% | 每2人就有1人 |
| 大約33% | 每3人就有1人 |
| 大約25% | 每4人就有1人 |
| 大約20% | 每5人就有1人 |
| 大約10% | 每10人就有1人 |
| 大約67% | 每3人就有2人 |
| 大約75% | 每4人就有3人 |

換說法時，**要選最接近的，不能為了嚇人而誇大**。例如27%比較接近「每4人就有1人」，不能寫成「每3人就有1人」。這跟第十週圖表的縱軸要從0開始是同一個道理：數字要誠實。

如果你選的是Q3（平均分數），大數字可以直接寫分數，例如「4.2分／滿分5分」，標題寫清楚這個分數在問什麼。

### 提醒不是把數字再說一次

| ✗ 只把數字再說一次 | ✓ 告訴大家要做什麼 |
| --- | --- |
| 35%的人共用密碼 | 帳號密碼，只給自己 |
| 很多人公開生日 | 生日不要當密碼 |
| 大家都收過可疑連結 | 奇怪的連結，先別點 |

動手之前，先在紙上或資料筆記的旁邊，把你的五個區塊寫出來。

## 三、登入Canva

1. 打開你的**學校Email**，找到老師寄的「**加入Canva班級**」邀請信，點信裡的連結加入班級
2. 選「**以Google帳號繼續**」，用**學校的Google帳號**登入
3. 點下面的範本連結，按「**使用範本**」，Canva會幫你建立一份**自己的副本**：<a href="PLACEHOLDER_CANVA_TEMPLATE_URL" target="_blank" rel="noopener">宣傳單範本</a>
4. 點左上角的檔名，改成「**W12宣傳單_<span data-class-code>7XX</span>_座號_姓名**」

範本上已經排好五個區塊的位置，你要做的是換成自己的內容，再調整成你喜歡的樣子。

## 四、動手做

照下面的順序做，**先把內容放齊，最後再調顏色和字體**。

### 第一步：換文字

點範本上的文字框兩下，把大數字、標題、提醒、資料來源換成你自己的。

- 文字太長擠不下時，先試著刪字，不要直接把字縮小
- 大數字一定要是全張最大的字

### 第二步：放圖表

選一種做法：

**做法一：用第十週的圖表（比較快）**

1. 打開你的試算表，切到「**比較表**」分頁
2. 點你選的那張圖表，按右上角的「**⋮**」→「**下載**」→「**PNG 圖片 (.png)**」
3. 回到Canva，點左邊的「**上傳**」→「**上傳檔案**」，選剛剛下載的圖片
4. 上傳完成後，點一下圖片就會放進宣傳單，拖到範本的圖表位置

**做法二：在Canva重做一張（可以自己配色）**

1. 點左邊的「**元素**」，往下找到「**圖表**」，選「**長條圖**」
2. 右邊會出現表格，把「我們班」和比較對象的數字填進去（例如 35 和 25）
3. 點其中一根柱子，可以改顏色。把「**我們班**」那根改成最醒目的顏色，比較對象用灰色，讓人一眼看到重點

不管用哪一種，**圖表上的數字都要跟第十週的比較表一樣**。

### 第三步：加一張圖片或圖示

點左邊的「**元素**」，用關鍵字搜尋，例如「密碼」、「手機」、「鎖」。

- 只能用**Canva素材庫裡的**圖片和圖示，不要從Google圖片下載別人的圖。這就是第五週學的合理使用：網路上的圖片大多有著作權，不能直接拿來用
- 如果你用Canva的AI功能生成圖片，要在圖片旁邊用小字標示「**AI生成**」，讓看的人知道這不是你畫的
- 圖片是配角，不能比大數字還搶眼

### 第四步：調整版面

| 原則 | 怎麼檢查 |
| --- | --- |
| 字體最多2種 | 大數字、標題用一種，其他文字用一種 |
| 顏色最多3種 | 一個主色、一個強調色（給大數字）、一個底色 |
| 對齊 | 拖曳時出現的紫色線就是對齊線，讓東西對齊同一條線 |
| 留白 | 四周留一點空白，不要把整張塞滿 |

## 五、自我檢查

做完先自己檢查一次：

- [ ] 大數字是全張最大的字，而且跟比較表上的一樣
- [ ] 提醒是告訴大家要做什麼，不是把數字再說一次
- [ ] 有圖表，看得出我們班和比較對象誰比較高
- [ ] 最下面有資料來源
- [ ] 圖片來自Canva素材庫；用AI生成的有標示「AI生成」
- [ ] 字體不超過2種、顏色不超過3種

再跟隔壁同學交換螢幕，讓對方看你的宣傳單**3秒**，然後問他：「這張在提醒什麼？」對方答得出來，就過關了；答不出來，回去把最重要的字放大、把不重要的刪掉。

## 六、繳交

1. 在Canva右上角點「**分享**」
2. 「協作連結」改成「**知道連結的任何人**」，權限選「**可檢視**」
3. 點「**複製連結**」
4. 打開下方的「**第十二週繳交表單**」，貼上連結，再填你的大數字和提醒

**今天的課堂作業：** 宣傳單做完並通過自我檢查，繳交表單送出。宣傳單會和之後的四格漫畫、成果發表一起算進段考3的成績，老師會照第五節的檢查表評分。
