## 學習目標

- 會用「詢問＿並等待」和「回答」讓玩家輸入數字
- 會用「隨機取數」讓電腦出題，用「字串組合」把文字和變數接在一起說出來
- 能照著虛擬碼，從空白專案完成一輪猜數字遊戲
- 會用「先把答案固定」的方法測試程式，並依照錯誤現象找出問題

## 一、上週複習：照著第3關寫

上週闖關第3關排出來的步驟，就是今天要寫的程式：

```
當綠旗被點擊
將「答案」設為（隨機取數 1 到 100）
將「次數」設為 0
將「猜測」設為 0
重複直到 ＜「猜測」＝「答案」＞
　詢問「猜一個1～100的數字」並等待
　將「猜測」設為「回答」
　將「次數」改變 1
　如果「猜測」＞「答案」那麼　說「太大了」
　如果「猜測」＜「答案」那麼　說「太小了」
說「答對了！你猜了（次數）次」
```

寫的時候有兩件事最容易弄錯：

- **先詢問，才有「回答」**
  <span class="explain">「詢問」要放在迴圈最上面，玩家輸入之後，才能拿「回答」去比。</span>
- **先存進「猜測」，才比大小**
  <span class="explain">比大小、判斷要不要停，都用「猜測」，不要直接用「回答」。</span>

## 二、今天的三個新積木

| 積木 | 在哪個分類 | 做什麼 |
| --- | --- | --- |
| 隨機取數 1 到 100 | 運算 | 每次執行都從1～100裡隨便挑一個整數 |
| 詢問＿並等待／回答 | 偵測 | 「詢問」會在舞台下方跳出輸入框，等玩家打字按Enter；玩家打的內容會存在「回答」裡 |
| 字串組合＿＿ | 運算 | 把兩段文字接成一段，例如「字串組合（蘋果）（香蕉）」會變成「蘋果香蕉」 |

最後那句「答對了！你猜了5次」是三段接起來的：「答對了！你猜了」＋（次數）＋「次」。字串組合一次只能接兩段，所以要**兩個疊在一起**：

```
說（字串組合（字串組合「答對了！你猜了」（次數））「次」）
```

先把裡面那個接好（「答對了！你猜了」＋次數），再把它整個放進外面那個的第一格，第二格打「次」。

## 三、開新專案、建立三個變數

這週從**空白專案**開始，這個專案就是你的期末專題，之後三週都會繼續加功能。

1. 登入自己的Scratch帳號，點「建立」開一個新專案
2. 專案名稱改成「猜數字」
3. 到「變數」分類，按「建立一個變數」，分別建立 **答案**、**猜測**、**次數** 三個變數，並刪除原有的變數「My Variable」
   <span class="explain">建立時選「適用於所有角色」（預設就是這個，不用改）。</span>

**⚠️ 變數名稱要打得一模一樣，小貓角色（Sprite1）不要刪掉、不要改名，程式都寫在小貓身上。** 系統會用這些名稱去比對你的結果，名稱不一樣就會判定成錯誤。

## 四、一步一步做

每做完一步就按綠旗試一次，確定沒問題再往下。

| 步驟 | 要做的事 | 按綠旗後應該看到 |
| --- | --- | --- |
| ① | 「當綠旗被點擊」下面接三個「將＿設為」：答案設為隨機取數1到100、次數設為0、猜測設為0 | 程式可以執行、沒有出錯；「答案」先不要勾選顯示在舞台上（第六節測試時再打開） |
| ② | 接「重複直到」，條件放「猜測＝答案」；迴圈裡放「詢問_請輸入猜測數字_並等待」和「變數 猜測 設為 詢問的答案」 | 舞台下方出現輸入框，打數字按Enter後，「猜測」變成你打的數字 |
| ③ | 迴圈裡接「將次數改變1」 | 每猜一次，「次數」加1 |
| ④ | 迴圈裡接兩個「如果…那麼」：猜測＞答案 就 說出「太大了」，猜測＜答案 就 說出「太小了」 | 猜錯會有提示（但先看下一節） |
| ⑤ | 迴圈**下面**（不是裡面）接「說出」，用兩個字串組合說「答對了！你猜了（次數）次」 | 猜中之後，小貓說出猜了幾次 |

**最後那句要用「說」，不要用「說＿持續＿秒」**，讓「答對了」一直留在畫面上。

## 五、試玩後發現：提示不見了！

照上面做完，試玩一次，你很可能會發現：**小貓好像從來沒說過「太大了」「太小了」。**

程式沒有寫錯，是動作太快：小貓說完「太大了」，迴圈馬上回到最上面執行「詢問」，**詢問的問題會出現在小貓的對話框裡，把「太大了」蓋掉**，快到眼睛看不到。

修正方法：把兩個提示換成 **「說出＿持續2秒」**。

| 原本 | 改成 |
| --- | --- |
| 說「太大了」 | 說「太大了」持續 2 秒 |
| 說「太小了」 | 說「太小了」持續 2 秒 |

這就是上週學的**追蹤與除錯**：一步一步想程式到底做了什麼，就能找出「明明有寫，卻沒看到」的原因。

## 六、怎麼測試？先把答案固定

答案每次都是隨機的，你不知道答案，就很難判斷電腦說的對不對。工程師遇到這種情況，會**先把隨機的部分固定下來**再測試：

1. 把「將答案設為（隨機取數1到100）」暫時改成「將答案設為 **40**」，並在變數勾選答案
2. 按綠旗，照上週第5關的順序輸入：**50、25、37、43、40**
3. 對照下表

| 輸入 | 小貓應該說 | 次數 |
| --- | --- | --- |
| 50 | 太大了 | 1 |
| 25 | 太小了 | 2 |
| 37 | 太小了 | 3 |
| 43 | 太大了 | 4 |
| 40 | 答對了！你猜了5次 | 5 |

4. 全部對了，**記得把答案改回「隨機取數1到100」**，變數裡「答案」的勾也取消，不然玩的人會直接看到答案

**系統批改時也是這樣測**：它會把答案固定成**另一個數字（不是40）**，一樣用「每次猜中間」的方法一路猜到答對，然後檢查答案、猜測、次數三個變數，還有小貓最後說的話。所以答案一定要改回「隨機取數」，如果還寫死成40，系統就會判定錯誤。

## 七、壞掉了怎麼辦？看現象找原因

上週第6關的四種錯誤，就是最常見的狀況：

| 看到的現象 | 去檢查 |
| --- | --- |
| 猜中的時候，還先說了「太小了」 | 是不是用了「如果…否則」？要用**兩個「如果…那麼」** |
| 最後永遠說「猜了1次」 | 「次數改變1」是不是放到迴圈**外面**了？ |
| 一直說「太小了」，停不下來 | 是不是少了「將猜測設為回答」？ |
| 一開始還沒猜，就說「猜了0次」 | 判斷條件是不是直接用「回答」？要用「猜測」 |
| 答對的那句話只閃一下就不見 | 最後那句是不是用了「說＿持續＿秒」？改成「說」 |
| 「答對了！你猜了5次」字不一樣 | 「！」是全形的嗎？「次」有沒有接上去？ |

## 八、今天的任務：解碼行動

完成一輪可以玩的猜數字遊戲：

- [ ] 答案用「隨機取數1到100」產生（測試完有改回來）
- [ ] 玩家可以一直猜，猜中才停
- [ ] 猜錯會提示「太大了」或「太小了」，而且看得到（第五節）
- [ ] 猜中後說「答對了！你猜了（次數）次」

完成後要準備兩個檔案：

1. **執行結果截圖**：按綠旗玩一輪，猜中之後，用第二週教過的截圖方法，把**整個舞台區**截下來（要看得到「答對了！你猜了○次」）。存成PNG或JPG都可以。
2. **專案檔**：用Scratch選單「檔案→下載到你的電腦」把專案下載下來（副檔名`.sb3`），依照第二週教過的檔名格式重新命名。

另外，記得在Scratch網站上**按「儲存」**，下週要接著做這個專案。

## 九、操作提示

1. 到Scratch網站登入自己的帳號，點上方「建立」
2. 左上角專案名稱改成「猜數字」
3. 「變數」分類 → 「建立一個變數」，建立答案、猜測、次數
4. 照第四節一步一步拼積木，每一步都按綠旗試試看
5. 照第五節把兩個提示改成「說出＿持續2秒」
6. 照第六節把答案暫時改成40，輸入50、25、37、43、40對照表格
7. 把答案改回「隨機取數1到100」
8. 按綠旗玩一輪，猜中後截下整個舞台區的畫面
9. 按「儲存」，再用「檔案→下載到你的電腦」下載`.sb3`，依格式重新命名（`班級_座號_姓名_MMDD猜數字.sb3`）

## 十、挑戰題（做完的人可以試試，不計分）

**挑戰1：告訴玩家範圍**

多建立「最小」「最大」兩個變數，一開始設成1和100。猜太大，就把「最大」設成「猜測－1」；猜太小，就把「最小」設成「猜測＋1」。再用字串組合讓小貓說「太大了，答案在1～49之間」。

這跟第十週二分搜尋的「左」「右」是一樣的想法：每猜一次，範圍就縮小一半。

**挑戰2：最多猜7次**

上週第8關算過，1～100用猜中間的方法最多7次就一定猜得到。把「重複直到」的條件改成（猜測＝答案）**或**（次數＝7），7次都沒猜中，就說出答案是多少。

兩個挑戰都可以直接做在要交的專案裡，只要**最後那句「答對了！你猜了（次數）次」不變**，系統就能正常批改。
