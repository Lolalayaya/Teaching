## 學習目標

- 用 `=` 引用其他儲存格的數字，建立一張比較表
- 算出兩個比例相差幾個「百分點」
- 把多組數字做成柱狀圖，一眼看出誰高誰低，並知道單位不同的數字要分開畫
- 判斷一個比較公不公平，寫出一句有數字根據的「我們發現⋯」

## 一、上週回顧：這樣說對嗎？

上週每組都算出了「我們班」的答案。先看一組全年級的數字：

> 全年級有 **50.3%** 的同學，註冊App時勾過「我已經符合使用年齡」，但其實沒有。
> 兒福聯盟2026年調查全台11,920位國中生，這個比例是 **42.4%**。

可以因此說「我們學校的人比較愛說謊」嗎？先想一想，等一下比較數字的時候，要隨時問自己下面四個問題：

| 問題 | 例子 |
| --- | --- |
| **誰被問？** | 國中生、高中生，還是大人？ |
| **什麼時候問？** | 2020年和2026年，大家用網路的習慣不一樣 |
| **問法一樣嗎？** | 「給過網友個資」和「給過電話、地址、學校」，範圍不一樣 |
| **問了多少人？** | 我們班大約20人，一個人就占5%；調查問了一萬多人 |

這四個問題都不一樣，不代表就不能比較，而是寫結論時要說清楚。

## 三、建比較表：三題一次算完

比較表統一做在**新分頁**，不要跟上週的問卷資料擠在一起：

1. 點試算表左下角的「**＋**」（新增工作表），下方會多一個分頁
2. 在新分頁的名稱上按兩下，改名為「**比較表**」
3. 原本的「問卷資料」分頁不要刪，等一下要從那裡拿數字

在「比較表」分頁從A1開始，做一張這樣的表。**三題都要填**：

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| **第1列** | 題目 | 我們班 | 全年級 | 全國 | 差距 |
| **第2列** | Q1 | | | | |
| **第3列** | Q2 | | | | |
| **第4列** | Q3 | | | （空著） | |

### 第一步：填題目

題目不用自己打：回到「問卷資料」分頁，在第1列選取你們組的3個題目格，按 `Ctrl+C` 複製；切到「比較表」分頁，在A2按右鍵 →「**選擇性貼上**」→「**轉置貼上**」，橫的3格就會變成直的3格。貼上後把題目改短一點，例如「謊報年齡註冊」，圖表上的字才不會太長。

### 第二步：填數字

- **我們班**：不要重新打數字。在B2輸入 `=`，**不要按Enter**，直接點下方的「問卷資料」分頁，找到上週算好的那一格點一下，再按Enter，就會自動跳回「比較表」。Q1、Q2點「Yes的比例」，Q3點「平均分數」。這叫做**儲存格參照**：公式會變成像 `='問卷資料'!F38` 這樣，驚嘆號前面是分頁名稱，後面是哪一格；上週的數字如果改了，這裡會跟著改
- **全年級**：照上面的表打進去，例如 `50.3%`；Q3打平均分數，例如 `4.59`
- **全國**：照上面的表打進去；沒有全國數字的題目，這一格空著。Q3三組都沒有全國數字，一定是空的

### 第三步：算差距

在「差距」那一欄算「我們班 − 比較對象」：

| 題目 | 比較對象 | 公式（以Q1在第2列為例） | 格式 |
| --- | --- | --- | --- |
| Q1、Q2 有全國數字 | 全國 | `=B2-D2` | 按「**%**」按鈕 |
| Q1、Q2 沒有全國數字 | 全年級 | `=B2-C2` | 按「**%**」按鈕 |
| Q3 | 全年級 | `=B4-C4` | 不用按%，是「分」 |

- Q1、Q2算出來如果是 **9.6%**，要說「高了 **9.6個百分點**」，不是「高了9.6%」。兩個比例相減，單位叫做「百分點」
- Q3算出來如果是 **0.3**，就是「高了 **0.3分**」
- 算出負數，代表我們班比較低

## 四、做成柱狀圖

Q1、Q2是比例（0%～100%），Q3是分數（1～5分），**單位不一樣，不能放在同一張圖**：Q3的4.5分會被當成450%，柱子會比其他的高很多，Q1、Q2反而看不清楚。所以要做兩張圖。

### 圖表一：Q1、Q2 的比例

1. 在「比較表」分頁，用滑鼠從A1拖到D3（「題目」到Q2那一列的「全國」）。**不要選到「差距」那一欄和Q3那一列**
2. 點上方選單「**插入**」→「**圖表**」，右邊會出現「圖表編輯器」
3. 在「**設定**」分頁：
   - 「圖表類型」選「**柱狀圖**」（柱子直直往上的那一種，不是橫的「長條圖」）
   - 往下捲，勾選「**使用第1列作為標題**」和「**使用A欄作為標籤**」
   - 檢查「X軸」是「題目」，「系列」有三個：我們班、全年級、全國。如果X軸變成「我們班、全年級、全國」，點一下「**切換列/欄**」
4. 切到「**自訂**」分頁：
   - 「圖表和軸標題」→ 標題改成「我們班 vs 全年級 vs 全國」
   - 「系列」→ 上面的下拉選單維持「套用到所有系列」，往下勾選「**資料標籤**」。資料標籤預設不會出現，一定要自己勾，每根柱子上才會顯示數字
   - 「縱軸」→「最小值」填 `0`、「最大值」填 `1`。比例在試算表裡是0到1的小數，1就是100%；這樣柱子會從0%畫到100%，不會誇大差距

做好之後檢查一次：

- 每一題有三根柱子，下方的圖例寫著「我們班」、「全年級」、「全國」
- 沒有全國數字的題目只有兩根柱子，這是正常的
- 柱子上的數字跟比較表一樣

### 圖表二：Q3 的平均分數

1. 先選取「題目」到「全年級」那三格標題（**A1到C1**），按住 `Ctrl` 不放，再選Q3那一列的三格（**A4到C4**），兩塊都會變成選取狀態
2. 「插入」→「圖表」，在「**設定**」分頁：
   - 「圖表類型」選「**柱狀圖**」
   - 「**切換列/欄**」**不要勾選**
   - 「**使用第1列作為標題**」和「**使用A欄作為標籤**」**保持勾選**
3. 「自訂」→「圖表和軸標題」，標題改成「Q3平均分數：我們班 vs 全年級」
4. 「自訂」→「系列」，勾選「**資料標籤**」（一樣預設不會出現）
5. 「自訂」→「縱軸」，「最小值」填 `1`、「最大值」填 `5`，跟量表的分數範圍一樣

## 五、寫「我們發現」

從三題裡選一題差距最明顯、最想讓大家知道的，照下面的句型寫一句：

> 我們班有 ○% 的人＿＿＿，比〔全國調查／全年級〕的 ○%〔高／低〕○ 個百分點，所以＿＿＿。
> 不過，＿＿＿（例如：這份調查問的是高中生和國中生／是2020年的調查／我們班只有20人）。

選Q3的話，第一句改成：「我們班的平均是 ○ 分，比全年級的 ○ 分〔高／低〕○ 分，代表＿＿＿。」

**「所以」、「代表」後面要寫什麼？** 寫這個數字讓你想到的事，可以從下面挑一種：

- **這個數字說明了什麼**：例如「跟朋友共用帳號密碼，在我們班比想像中常見」
- **可能會發生什麼危險**：例如「只要其中一個人的帳號被盜，大家的帳號都會跟著出事」
- **想提醒大家做什麼**：例如「每個帳號都要設自己的密碼，也不要告訴朋友」

不要只把數字再說一次（例如「所以有35%的人跟朋友共用密碼」），要說出數字背後的意思。這一句會變成下週宣傳單上的提醒，寫得越具體越好。

第二句是「注意事項」：用第一節的四個問題檢查一次，把最大的不同寫出來。

### 範例

下面的題目和數字都是**虛構的**，只是示範怎麼寫，不是任何一組的題目。假設有一組問了這3題：

- Q1（是非）：你有沒有跟朋友共用同一組遊戲帳號密碼？
- Q2（是非）：你會不會在社群上公開自己的生日？
- Q3（量表）：你覺得設定一組不容易被猜到的密碼有多重要？（1分＝完全不重要／5分＝非常重要）

比較表算出來：Q1我們班35%、全國調查25%；Q2我們班60%、全年級52%（沒有全國數字）；Q3我們班4.2分、全年級4.5分。三題剛好各用一種「所以」的寫法：

**Q1（說明了什麼）**

> 我們班有35%的人跟朋友共用同一組遊戲帳號密碼，比全國調查的25%高10個百分點，所以共用帳號密碼在我們班比想像中常見，大約每3個人就有1個。
> 不過，這份全國調查是好幾年前做的，問的對象也包含高中生。

**Q2（可能會發生什麼危險）**

> 我們班有60%的人會在社群上公開自己的生日，比全年級的52%高8個百分點，所以很多人的生日別人都查得到；生日常被拿來當密碼或驗證問題，被猜中的風險就變高了。
> 不過，沒有找到全國的調查，全年級也只代表我們學校，不能說全國都是這樣。

**Q3（想提醒大家做什麼）**

> 我們班覺得設定不容易被猜到的密碼有多重要，平均是4.2分，比全年級的4.5分低0.3分，代表大家都知道密碼很重要，但還是要提醒自己，不要用生日或123456當密碼。
> 不過，我們班只有20人，換幾個人回答，平均就可能不一樣。

**比一比：**

| ✗ 只把數字再說一次 | ✓ 說出數字背後的意思 |
| --- | --- |
| 所以有60%的人會公開生日。 | 所以很多人的生日別人都查得到；生日常被拿來當密碼，被猜中的風險就變高了。 |

### 你們組的句型

找到你們這組，選一題，把＿＿換成比較表上的數字，〔高／低〕留下對的那一個，「所以」後面寫你們想提醒大家的事。「不過」那一句已經寫好最主要的不同，可以照抄，也可以改成你們找到的其他不同。

#### 個資保護・第一組

**Q1**

> 我們班有＿＿%的人曾把電話、地址或學校告訴只在網路上認識的人，比全國調查的41%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，全國調查問的是「給過網友個資」，範圍比我們的題目大，而且包含高中生。

**Q2**

> 我們班有＿＿%的人會開啟定位，讓對方知道自己在哪裡，比全國調查的27.7%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，這份全國調查是2020年做的，現在大家用App的習慣可能不一樣了。

**Q3**

> 網路上認識的人跟我們要電話或地址時，我們班的猶豫程度平均是＿＿分，比全年級的4.53分〔高／低〕＿＿分（5分＝絕對不會給），代表＿＿＿＿。
> 不過，我們班只有＿＿人，換幾個人回答，平均就可能不一樣。

#### 個資保護・第二組

**Q1**

> 我們班有＿＿%的人覺得姓名和手機號碼不算需要保密的資料，比全國調查的20%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，這份全國調查是2020年做的，問的是全台兒少，不只國中生。

**Q2**

> 我們班有＿＿%的人註冊App時謊報過年齡，比全國調查的42.4%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，我們班只有＿＿人，一個人就占了大約＿＿%，只要幾個人答得不一樣，比例就會差很多。

**Q3**

> 我們班覺得在網路上公開姓名或手機號碼的風險，平均是＿＿分，比全年級的4.59分〔高／低〕＿＿分（5分＝非常危險），代表＿＿＿＿。
> 不過，我們班只有＿＿人，換幾個人回答，平均就可能不一樣。

#### 資訊安全・第一組

**Q1**

> 我們班有＿＿%的人收過投票、中獎、包裹通知這類可疑連結，比全國調查的40%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，全國調查問的是「遇過網路詐騙」，跟「收過可疑連結」問法不太一樣。

**Q2**

> 我們班有＿＿%的人收到可疑連結會先查證，比全國調查的50%〔高／低〕＿＿個百分點，所以＿＿＿＿。
> 不過，全國調查問的是「遇過詐騙的兒少」，我們問的是全班，對象不完全一樣。

**Q3**

> 收到「幫我投票」的連結時，我們班想點進去的程度平均是＿＿分，比全年級的1.61分〔高／低〕＿＿分（1分＝完全不會點，分數越低越安全），代表＿＿＿＿。
> 不過，我們班只有＿＿人，換幾個人回答，平均就可能不一樣。

#### 資訊安全・第二組

**Q1**

> 我們班有＿＿%的人如果被詐騙，會因為怕被罵而不敢跟家人說，比全國調查的30%〔高／低〕＿＿個百分點，所以＿＿＿＿。
