## 學習目標

- 複習全形／半形標點的差異與三種打出中文標點的方法
- 複習表情符號面板、截圖與貼上的操作
- 複習之後所有作業通用的檔名格式

這份講義整理的是這週特務闖關解謎會用到的知識，等大家都闖關結束後再回來看，可以當作總複習。

## 一、全形半形標點複習

中文標點（例如「；」「，」）是全形、英文鍵盤直接打出來的（例如「;」「,」）是半形。中文打字要用全形標點，字距才會跟中文字對齊。如果打英文時字距突然變超寬，多半是不小心切到全形模式了，按 `Shift+空白鍵`（或全／半形切換鍵）就能切回半形。

## 二、中文標點打法複習

| 符號 | Ctrl 版 | 反引號版 |
| --- | --- | --- |
| 「，」 | Ctrl + , | `+, |
| 「。」 | Ctrl + . | `+. |
| 「、」 | Ctrl + ' | `+' |
| 「；」 | Ctrl + ; | `+; |
| 「：」 | Ctrl + Shift + ; | `+Shift+; |
| 「？」 | Ctrl + Shift + / | `+Shift+/ |
| 「！」 | Ctrl + Shift + 1 | `+Shift+1 |

也可以按 `Ctrl+Alt+ㄝ`（逗號鍵）叫出輸入法內建的符號輸入板，直接點選標點。

## 三、表情符號與截圖複習

**表情符號**：`Win + 句號（.）` 叫出 Windows 表情符號面板。

**截圖與貼上**：`Win+Shift+S` 自由選取畫面截圖，截完進剪貼簿，`Ctrl+V` 貼上。

## 四、檔名格式複習

所有作業檔案都用這個格式命名：

```
班級_座號_姓名_日期與作業名稱
```

底線「_」按 `Shift` + 「－」鍵（在數字 0 右邊）。

| 段落 | 規則 | 範例 |
| --- | --- | --- |
| 班級 | 年級（1、2、3、7、8、9 其中一碼）＋班級（01～12） | 701 |
| 座號 | 01～30 | 05 |
| 姓名 | 2～4 個中文字，請打全名，不要打綽號 | 王小明 |
| 日期＋文字 | 4 碼日期，後面至少要有「截圖」兩個字 | 0907截圖任務 |

合起來就是「701_05_王小明_0907截圖任務.png」（僅為範例，請填寫你自己的班級、座號、姓名及當天日期與作業內容）。
