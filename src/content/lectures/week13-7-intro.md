## 學習目標

- 用3秒測試和排版的七個重點，看出一張宣傳單哪裡需要修改
- 給同學一個具體的修改建議，說清楚要改哪裡、怎麼改
- 依照收到的建議修改自己的宣傳單，並寫下改了什麼
- 判斷哪些圖片和資料可以放進宣傳單，以及要怎麼標示

## 一、3秒測試

老師會投影幾張宣傳單（不顯示姓名），每張只停**3秒**。看完說出：這張宣傳單在提醒什麼？

說不出來的那一張，一起找原因。常見的原因有：

- 大數字不夠大，跟其他字差不多
- 提醒混在一堆字中間，沒有獨立出來
- 顏色太多，每個地方都很搶眼

這些都是第十二週講義「三、排版的七個重點」裡的內容。今天就用這七個重點，幫同學的宣傳單找問題。

## 二、先把宣傳單做完

**還沒做完或還沒繳交的同學：** 先回到<a href="../week12-7-intro/">第十二週講義</a>，照第五節的步驟做完，再到第七節繳交。

**已經繳交的同學：** 打開自己的宣傳單，照第十二週講義第六節的自我檢查，再看一次。

10分鐘後，不管做到哪裡，都要進行下一步的互評。還沒做完的宣傳單也可以給同學看，越早拿到建議，越知道要怎麼改。

## 三、互評

和隔壁同學兩人一組，交換看彼此的螢幕。人數是單數的話，老師會安排一組三個人。

1. **3秒測試**：看對方的宣傳單3秒就轉開，寫下你覺得它在提醒什麼。寫完再問對方是不是想說這個
2. **看七個重點**：慢慢看一次，對照下表，勾出對方做到的項目
3. **一個優點＋一個建議**：建議要說清楚**改哪裡、怎麼改**

| 檢查項目 | 對照第十二週的 |
| --- | --- |
| 大數字是全張最大的字 | 排版重點1、2 |
| 提醒是叫大家去做一件事，而且有獨立出來 | 第二節、排版重點4 |
| 有圖表，看得出誰比較高 | 第五節第二步 |
| 最下面有資料來源 | 第二節 |
| 顏色不超過3種、字體不超過2種 | 排版重點5 |
| 東西有對齊，四周有留白 | 排版重點6、7 |

建議怎麼寫才有用：

| ✗ 對方不知道要怎麼改 | ✓ 對方看了就能動手改 |
| --- | --- |
| 再漂亮一點 | 背景換淺色，大數字才會比較明顯 |
| 字太多 | 「為什麼危險？」每一點刪到一行 |
| 提醒不明顯 | 提醒放大，加一個色塊，移到最下面 |

寫完之後，**把建議當面說給對方聽**，再把結果填進下方表單的第一部分。

## 四、修改

照同學給你的建議修改宣傳單。如果你不同意某個建議，可以不改，但要想清楚為什麼。

- 在Canva上直接改就好，**不用重新繳交**。第十二週繳交的連結會自動顯示最新的版本
- 改完再做一次3秒測試：請同學看3秒，這次他說得出來了嗎？
- 改完把表單的第二部分填好：你改了什麼？是根據哪一條建議？

## 五、圖片和資料可以怎麼用

宣傳單上的東西不一定都是自己做的，圖片、圖示、數字常常是從別的地方來的。能不能用、要怎麼標示，可以照這張表判斷：

| 來源 | 可以用嗎 | 要怎麼做 |
| --- | --- | --- |
| Canva素材庫的圖片、圖示 | 可以 | 改顏色、改大小都可以 |
| 用Canva的AI功能生成的圖片 | 可以 | 在圖片旁邊用小字標示「AI生成」 |
| 從Google圖片下載的圖片 | 不行 | 網路上的圖片大多有著作權，改用Canva素材庫 |
| 調查報告或新聞裡的數字 | 可以 | 寫出資料來源：哪個單位、哪一年、調查的對象 |

這就是第五週學過的合理使用：用別人的東西時，要確定可以用，並讓看的人知道它是從哪裡來的。表單的第三部分有三題情境題。

## 六、繳交

填好下方的「**第十三週互評與修改表單**」：

- 第一部分：你幫誰看了宣傳單，給了什麼建議
- 第二部分：你自己的宣傳單改了什麼
- 第三部分：三題情境題

**評分方式：** 宣傳單會在這堂課結束後，照第十二週第六節的檢查表評分，看的是你**修改後的版本**。這份表單另外算一次成績。兩份都會算進段考3。
