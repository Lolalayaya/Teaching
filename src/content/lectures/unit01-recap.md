## 學習目標

- 複習基本電腦操作：鍵盤定位、滑鼠、視窗按鈕、Caps Lock、中英文切換、快捷鍵、副檔名
- 複習二進位與十進位的換算方法、ASCII 碼與摩斯密碼

這份講義整理的是第一週密室逃脫解謎會用到的知識，等大家都闖關結束後再回來看，可以當作總複習。

## 一、基本操作複習

**鍵盤定位點**：F 鍵和 J 鍵上面有兩個凸起的小點，是打字時手指定位用的，讓你不用看鍵盤也能找到正確的位置。

**滑鼠三個動作**：單擊（左鍵按一下）用來選取；雙擊（左鍵快速點兩下）用來開啟檔案或資料夾；右鍵用來叫出選單，看看能對這個東西做什麼操作。

**視窗右上角三個按鈕**：由左到右通常是 `—` 最小化（收到工作列，視窗還在）、`□` 最大化／還原（放到滿版或還原成原本大小）、`✕` 關閉（真正關掉這個視窗）。

**Caps Lock**：鍵盤左邊的 Caps Lock 鍵按下去會鎖定英文大寫模式，打出來的字母會全部變大寫，再按一次可以解除。如果發現打出來的字母大小寫怪怪的，先檢查這個鍵有沒有不小心被按到。

**中英文輸入切換**：依電腦設定不同，常見的是 `Shift` 鍵，也有些系統用 `Ctrl+Shift`。螢幕右下角的輸入法圖示會顯示目前是中文還是英文模式。

**常用快捷鍵**：

| 快捷鍵 | 功能 |
| --- | --- |
| Ctrl+Z | 復原剛剛的動作 |
| Ctrl+C | 複製 |
| Ctrl+V | 貼上 |
| Ctrl+X | 剪下 |

**檔案副檔名**：檔名最後面「.」之後的英文字母叫做副檔名，用來告訴電腦這是什麼類型的檔案。例如 `.docx` 是文件檔、`.jpg` 是圖片檔、`.mp3` 是音樂檔、`.exe` 是可執行的程式檔（來路不明的 .exe 檔不要亂點開）。

## 二、二進位與十進位換算

電腦內部只用 0 與 1（二進位）儲存所有資料。

**二進位轉十進位**：把每一位由右到左，依序對應 2⁰、2¹、2²……的位值，是 1 的位就加上該位值，是 0 的就不加，最後加總。

例如 `01110110`：

```
位值:   128  64  32  16   8   4   2   1
數字:     0   1   1   1   0   1   1   0
```

加總 = 64 + 32 + 16 + 4 + 2 = **118**

## 三、ASCII 碼

電腦用數字代表每一個英文字母，這套對應規則叫做 ASCII 碼。先把二進位換算成十進位，再對照 ASCII 表，就能找到對應的英文字母（例如十進位 118 對應小寫字母 `v`）。

## 四、摩斯密碼

摩斯密碼用「短音（`.`）」和「長音（`-`）」的組合代表每個英文字母，例如 `E` 是 `.`、`N` 是 `-.`、`D` 是 `-..`。不同字母之間會用空格隔開，解碼時要對照摩斯密碼表，一個字母一個字母慢慢拆解。

## 五、凱薩加密解密方法

密室逃脫最後，你會收集到一整串被加密過的句子，要解密才能過關。這個加密法叫做「凱薩加密」（Caesar Cipher）：加密的時候，把每個英文字母在字母表上往後移動固定的位數；解密的時候，反過來往前移動一樣的位數，就能還原成原本的句子。

例如，如果位移量是 3：

- 加密：`B` → `E`（B 往後移 3 位是 E）
- 解密：`E` → `B`（E 往前移 3 位是 B）

字母表是循環的，如果往前／往後移超過 A 或 Z，要繞回另一端（例如 A 往前移 3 位會繞到 X）。空格、標點符號不用移位，原封不動照抄。
