## 二、課堂規則

**「可以輕鬆，不可以隨便」**

1. 完成該堂課的作業後，可以自由活動（但僅限下面列出來的網站）。
2. 若無故打斷老師授課，會影響課程進度，並減少大家的自由時間。
3. 上課時竊竊私語，老師將讓你到前面與全班分享你的想法。
4. 發言前請先**舉手**，等老師點名後再發言。
5. 若有問題，請舉手詢問老師。
6. 上課前在教室外整隊，等待老師同意後全班**安靜脫鞋**後進入教室。
7. 請依照座號入座，如果設備有問題，需**先告知老師**後，才能更換座位。
8. 下課後，請將網頁登出並關機（Win鍵 → 電源鍵 → 關機），並將使用的設備及椅子**放回原位**，確保教室整潔，沒有遺留的垃圾後才可以離開。
9. 課堂上**禁止趴下**休息。如因身體不適需要休息，請提前告知老師。
10. 上課期間禁止離開教室，如果真的急需上廁所請舉手詢問老師。
11. 電腦教室禁止飲食，如因生病不得不喝水或吃藥請告知老師後到教室外處理。

## 六、二進位與十進位換算

電腦內部只用 0 與 1（二進位）儲存所有資料，等一下的密室逃脫會用到這個換算方法。

**二進位轉十進位**：把每一位由右到左，依序對應 2⁰、2¹、2²……的位值，是 1 的位就加上該位值，是 0 的就不加，最後加總。

例如 `01110110`：

```
位值:   128  64  32  16   8   4   2   1
數字:     0   1   1   1   0   1   1   0
```

加總 = 64 + 32 + 16 + 4 + 2 = **118**

## 七、凱薩加密解密方法

密室逃脫最後，你會收集到一整串被加密過的句子，要解密才能過關。這個加密法叫做「凱薩加密」（Caesar Cipher）：加密的時候，把每個英文字母在字母表上往後移動固定的位數；解密的時候，反過來往前移動一樣的位數，就能還原成原本的句子。

例如，如果位移量是 3：

- 加密：`B` → `E`（B 往後移 3 位是 E）
- 解密：`E` → `B`（E 往前移 3 位是 B）

字母表是循環的，如果往前／往後移超過 A 或 Z，要繞回另一端（例如 A 往前移 3 位會繞到 X）。空格、標點符號不用移位，原封不動照抄。

位移量在密室逃脫的關卡裡會另外提示你（藏在一個線索裡），找到位移量之後，把收集到的每個字母都往前移動那個數字，就能解出最後的句子。

## 八、今天的挑戰：密室逃脫解鎖電腦教室

準備好了嗎？[進入密室逃脫](../../escape-room/)，用**自己的電腦**單機闖關，把散落在各關的線索片段收集起來，解開電腦教室的最後一道鎖。

- 卡關超過5分鐘就直接舉手問老師，不用自己硬想。
- 最後一關要點選輸入框旁邊的色塊，打開瀏覽器內建的顏色選取器，用裡面的滴管工具，直接吸取題目畫面上表情符號的顏色，查出它的 Hex 色碼——不會用的話舉手問老師示範。
- 完成密室逃脫、看到大門開啟的畫面後，請舉手通知老師，讓老師確認完畫面後即完成本次作業，成績即為100分。
