## 學習目標

- 認識電腦教室的使用規則與評分方式
- 練習登入學校帳號
- 複習基本電腦操作：鍵盤定位、滑鼠、視窗按鈕、中英文切換、快捷鍵、副檔名
- 學會二進位與十進位的換算方法
- 透過密室逃脫遊戲，解鎖教室、找到班級公約

## 一、登入帳號

本學期的帳號密碼由學校統一發放，請依照老師現場說明的方式登入。如果登入失敗，請直接舉手詢問老師，不要自己重複嘗試太多次（帳號密碼打錯太多次可能會被鎖住）。

## 二、電腦教室使用規則

這些規則，呼應待會密室逃脫解開之後會看到的班訓：「可以輕鬆，不可以隨便」。

1. 完成該堂課的作業後，可以自由活動。
2. 若無故打斷老師授課，會影響課程進度，並減少大家的自由時間。
3. 上課時竊竊私語，老師將讓你透過麥克風與全班分享你的想法。
4. 發言前請先舉手，等老師點名後再發言。
5. 若有問題，請舉手詢問老師。
6. 上課前在教室外整隊，等待老師同意後全班安靜進入教室。
7. 請依照座號入座，如果設備有問題，需先告知老師後，才能更換座位。
8. 下課時，請將使用的設備及椅子放回原位，確保教室整潔後才可以離開。
9. 課堂上禁止趴下休息。如因身體不適需要休息，請提前告知老師。
10. 上課期間禁止離開教室，如果真的急需上廁所請舉手詢問老師。
11. 電腦教室禁止飲食，如因生病不得不喝水或吃藥請告知老師後到教室外處理。

## 三、下課後想問問題怎麼辦

上課中有任何問題，直接舉手詢問老師就好。如果是下課後想找老師，可以到 **教師辦公室1（凱風樓2樓，分機605）** 找曾老師。

## 六、二進位與十進位換算

電腦內部只用 0 與 1（二進位）儲存所有資料，等一下的密室逃脫會用到這個換算方法。

**二進位轉十進位**：把每一位由右到左，依序對應 2⁰、2¹、2²……的位值，是 1 的位就加上該位值，是 0 的就不加，最後加總。

例如 `01110110`：

```
位值:   128  64  32  16   8   4   2   1
數字:     0   1   1   1   0   1   1   0
```

加總 = 64 + 32 + 16 + 4 + 2 = **118**

## 七、凱薩加密解密方法

密室逃脫最後，你會收集到一整串被加密過的句子，要解密才能過關。這個加密法叫做「凱薩加密」（Caesar Cipher）：加密的時候，把每個英文字母在字母表上往後移動固定的位數；解密的時候，反過來往前移動一樣的位數，就能還原成原本的句子。

例如，如果位移量是 3：

- 加密：`B` → `E`（B 往後移 3 位是 E）
- 解密：`E` → `B`（E 往前移 3 位是 B）

字母表是循環的，如果往前／往後移超過 A 或 Z，要繞回另一端（例如 A 往前移 3 位會繞到 X）。空格、標點符號不用移位，原封不動照抄。

位移量在密室逃脫的關卡裡會另外提示你（藏在一個線索裡），找到位移量之後，把收集到的每個字母都往前移動那個數字，就能解出最後的句子。
