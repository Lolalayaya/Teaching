## 二、四格漫畫的故事秘密：起承轉合

一個能讓人記住的宣導故事，通常都有這四個階段：

| 階段 | 意思 |
| --- | --- |
| 起 | 主角遇到一個看起來無害的情境或誘因 |
| 承 | 主角一步步做出行動，事情持續發展 |
| 轉 | 事情急轉直下，後果出現 |
| 合 | 結局，帶出一句提醒觀眾的話 |

四格漫畫的四格，就直接對應這四個階段：第1格畫「起」、第2格畫「承」、第3格畫「轉」、第4格畫「合」。

### 範例：LINE帳號被盜案

警方查獲一種鎖定青少年的LINE帳號詐騙手法：詐騙集團傳送「幫我家小孩投票」、「幫寵物選拔集氣」之類的連結，一旦依照網頁指示輸入手機號碼、LINE密碼與簡訊驗證碼，帳號控制權就會在幾秒內轉移到詐騙集團手中。帳號被偷走後，詐騙集團會冒充本人向通訊錄裡的親友借錢或散布詐騙訊息，受害不只限於帳號本人，還會連累通訊錄裡所有認識的人。

（資料來源：<a href="https://news.ltn.com.tw/news/society/breakingnews/5529107" target="_blank" rel="noopener">自由時報，2026年</a>／<a href="https://www.ettoday.net/news/20260726/3207840.htm" target="_blank" rel="noopener">ETtoday新聞雲，2026年7月26日</a>）

| 階段 | 對照這個案例 |
| --- | --- |
| 起 | 收到一則「幫我家小孩投票」的訊息，點進去看起來只是個投票網頁 |
| 承 | 照著網頁指示輸入手機號碼、LINE密碼、簡訊驗證碼 |
| 轉 | 帳號瞬間被奪走，幾分鐘內就被拿去冒充身分向朋友借錢、散布詐騙訊息 |
| 合 | 一句提醒台詞，例如「奇怪的連結，先別急著點」 |

**示範寫法（等一下你們的Google文件也要打成這樣）：**

**起**
- 畫面：小明收到一則「幫我家小孩投票」的訊息
- 台詞：「才十秒，順手幫個忙而已」

**承**
- 畫面：小明依照網頁指示輸入手機號碼、LINE密碼、簡訊驗證碼

**轉**
- 畫面：手機突然跳出「你的帳號已在其他裝置登入」的訊息，帳號瞬間被奪走
- 台詞：「咦？我的LINE呢？」

**合**
- 畫面：好友收到「小明」傳來的借錢訊息
- 宣導金句：「奇怪的連結，先別急著點」

上面每一段開頭的「起」「承」「轉」「合」都用標題樣式，底下用項目符號列出畫面和台詞——這就是等一下你們要在Google文件裡打出來的格式。

## 三、Google文件的共編功能

### 怎麼分享一份Google文件

等一下每組要自己開一份新的Google文件，開好之後要自己設定分享權限，讓組員都能一起編輯：

1. 開啟文件之後，點右上角的「共用」按鈕
2. 「一般存取權」選「知道連結的任何人」，右邊的權限選「編輯者」——如果選「查看者」，別人只能看不能打字；選「意見提供者」則只能留言，不能直接修改內容
3. 點「複製連結」，把連結傳給組員（貼到公告的留言區中，或是傳送Email）
4. 組員點連結就能直接開始編輯，不需要另外申請權限
5. 如果想單獨分享給某個人（例如想指定給老師看），可以在「共用」視窗裡直接輸入對方的信箱，一樣要選「編輯者」或「意見提供者」

### 共編時你會看到什麼

同一份文件，組員可以同時打開、同時打字，不用你打完換我打。每個人打字的地方會顯示自己的名字和游標顏色，就能看到組員正在寫哪裡。如果對組員寫的內容有想法但不想直接刪掉，可以用「插入」→「留言」功能，把意見寫在旁邊，不要直接蓋掉別人打的字。

## 四、動手：開文件、設分享、打大綱、練排版

各組動手做以下步驟：

1. 組內推派一位同學，開一份新的Google文件（開啟Google雲端硬碟，點左上角「新增」→「Google文件」，或直接在瀏覽器網址列輸入 `docs.new`）
2. 依照上面「怎麼分享一份Google文件」的步驟，把這份文件分享給組員，設定為「編輯者」，確認每個人都能打開、都能打字
3. 先決定主角設定（姓名、年級、場景，全部虛構，不能真的指名道姓或影射任何真實同學）
4. 依照起承轉合分成四段打字：起、承、轉、合，每段各自打一段
5. 選取每一段開頭的字（例如「起」），點上方工具列「格式」→「段落樣式」→選「標題2」，變成小標題，方便區分四格
6. 每一格底下用項目符號清單（工具列的清單圖示）列出這一格的畫面重點和台詞
7. 如果同一格內想再分層次（例如畫面說明跟台詞分開），用Tab鍵或「增加縮排」按鈕做出層次
8. 最後留一行，寫下這則故事的宣導金句

這份大綱不用寫得很完整，能看出四格各自要畫什麼、主角會說什麼台詞就可以了——之後Google文件那幾堂課，會把這份大綱正式擴充成腳本初稿。
