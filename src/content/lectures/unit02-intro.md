## 一、全形標點 vs 半形標點

中文標點符號分成全形（例如「；」「，」）跟半形（例如「;」「,」）兩種，看起來很像，但寬度不一樣。中文打字習慣用**全形標點**，這樣標點才會跟中文字對得整齊、字距均勻好看。

**字距爆炸怎麼辦**：如果打英文的時候，發現字母跟字母之間的空隙突然變得超寬，通常是不小心切到了全形模式——按 `Shift+空白鍵`（或輸入法工具列上的全／半形切換鍵），就可以切回半形。

## 二、中文標點打法特輯

中文標點不在鍵盤上，要另外叫出來才能打，有三種常見方法：

**方法一・呼叫小鍵盤**：按下 `Ctrl+Alt+ㄝ`（也就是逗號鍵）可以叫出輸入法內建的「符號輸入板」，裡面有各種中文標點可以直接點選輸入。

**方法二・直接快捷鍵（Ctrl 版）**：

| 符號 | 快捷鍵 |
| --- | --- |
| 「，」 | Ctrl + , |
| 「。」 | Ctrl + . |
| 「、」 | Ctrl + ' |
| 「；」 | Ctrl + ; |
| 「：」 | Ctrl + Shift + ; |
| 「？」 | Ctrl + Shift + / |
| 「！」 | Ctrl + Shift + 1 |

**方法三・直接快捷鍵（反引號版）**：如果 Ctrl 版在你的電腦上沒作用，換成反引號鍵（`` ` ``，Esc 鍵下面那個鍵）也可以：

| 符號 | 快捷鍵 |
| --- | --- |
| 「，」 | `+, |
| 「。」 | `+. |
| 「、」 | `+' |
| 「；」 | `+; |
| 「：」 | `+Shift+; |
| 「？」 | `+Shift+/ |
| 「！」 | `+Shift+1 |

三種方法擇一熟悉即可，能穩定打出中文標點就好。

## 三、表情符號密碼

按下 `Win + 句號（.）` 會叫出 Windows 內建的表情符號面板，裡面可以搜尋、點選任何 emoji 直接輸入，不用另外安裝任何東西。

## 四、截圖蒐證複習

複習一下截圖方式：`Win+Shift+S` 可以自由選取畫面上的一個區域來截圖，截完會直接進到剪貼簿，接著在任何地方按 `Ctrl+V` 就能貼上——這跟你們上週學過的「貼上」快捷鍵是同一個。

## 五、正式歸檔：檔名格式

從今天開始，**所有作業檔案**都要用這個格式命名：

```
班級_座號_姓名_日期與作業名稱
```

底線「_」的打法是按住 `Shift` 再按「－」鍵（在數字 0 右邊）。每一段的規則如下：

| 段落 | 規則 | 範例 |
| --- | --- | --- |
| 班級 | 年級（1、2、3、7、8、9 其中一碼）＋班級（01～12） | 701 |
| 座號 | 01～30 | 05 |
| 姓名 | 2～4 個中文字，請打全名，不要打綽號 | 王小明 |
| 日期＋文字 | 4 碼日期，後面至少要有「截圖」兩個字 | 0907截圖任務 |

合起來就是「701_05_王小明_0907截圖任務.png」（以上僅為範例，請填寫你自己的班級、座號、姓名及當天日期）。之後每次交作業都會用同一套規則，先在這裡練熟。

如果找不到剛剛截圖存在電腦的哪裡，特務闖關頁面裡也提供了一個範例檔案可以下載，練習重新命名再上傳就好。

## 六、今天的挑戰：特務闖關・蒐證任務

準備好了嗎？[進入特務闖關](../../mission-2/)，用**自己的電腦**單機闖關，蒐集標點、表情、截圖、歸檔這幾項情報技能的線索片段，完成任務、結案回報。

- 卡關超過一點時間就直接舉手問老師，不用自己硬想。
- 完成後畫面會出現「任務完成」的動畫，舉手讓老師看一下就算完成這次任務。
