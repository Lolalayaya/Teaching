# 列隊行動・詳細步驟說明

這頁不會出現在網站選單或講義列表裡，是老師給覺得卡關、或時間快來不及的同學看的加強版說明。如果你已經照著講義裡的「操作提示」順利完成，不用特別看這一頁。

**還沒有Scratch帳號、或忘記帳號密碼？** 第4堂講義裡有「開始之前：註冊／登入Scratch帳號」完整說明，先處理好帳號問題再回來這頁繼續。

## 第一步：打開起始專案、變成自己的

1. 在講義頁面找到「列隊行動起始專案」的嵌入畫面。如果畫面顯示灰色的破圖示，不用擔心，這是正常的——點畫面下方的「在新視窗開啟」連結，會用新的分頁打開真正的Scratch頁面。
2. 確認自己已經登入Scratch帳號（右上角要看到自己的帳號名稱，不是「登入」兩個字）。
3. 找到「進去看看」（英文有時顯示 See inside）按鈕並點下去，會進到積木編輯畫面。
4. **這時候還不是你自己的專案**，你改的東西沒辦法存檔。要在畫面右上角找一個像「循環箭頭」的小按鈕，滑鼠移過去會顯示「改編」或「Remix」，點下去。
5. 點下去之後，網址列的專案編號會變成一組新的數字——這代表現在是你自己的專案了。之後隨時可以按 Ctrl+S 或選單「檔案→立即儲存」存檔。

## 第二步：看懂專案裡已經有什麼

打開後，你會看到：

- 一個清單「排行榜分數」，裡面是 790、980、650、875、860（順序故意是亂的）
- 四個變數：「輪次」「i」「最大值位置」「暫存」，數值目前都是0——這是正常的
- 一組已經寫好的積木，開頭是「當綠旗被點擊」：它會把清單清空，再重新放回這5個打亂的分數。**這組不用動，也不要刪掉**
- 一個空空的積木「當按下 s 鍵」，底下還沒有接任何東西——這就是你今天要蓋積木的地方

**⚠️ 清單的5個數字、跟四個變數的名稱，都不能更改。** 老師評分是拿你的結果跟參考答案逐項比對，被改掉的話系統會比對不出來。

**⚠️ 為什麼要先按綠旗？** 排序會直接改掉清單裡的數字。按過一次s，清單就已經排好了，再按s看起來還是排好的，你就看不出程式到底對不對。所以**每次測試都要先按綠旗，讓清單變回亂的，再按s**。

## 第三步：先蓋出「排一輪」

這一步先只排第1輪，做完可以馬上對答案，確定沒問題再往下。

### 3-1　起手式：三個「設為」

1. 在左側找「變數」分類（橘色系），找到「變數＿設為＿」這個積木
2. 拖到「當按下 s 鍵」下面接起來，第一個空格選「輪次」，後面填`1`
3. 再拖一個「變數＿設為＿」接在下面，第一個空格選「最大值位置」，後面空格**不要打數字**，把「輪次」這個變數積木拖進去
4. 再拖一個「變數＿設為＿」接在下面，第一個空格選「i」，後面一樣把「輪次」變數積木拖進去

做完應該是：

- 將「輪次」設為`1`
- 將「最大值位置」設為「輪次」
- 將「i」設為「輪次」

### 3-2　內層迴圈：重複（清單長度 − 輪次）次

1. 在「控制」分類（黃色系）找「重複＿次」這個C型積木，接在3-1的三個積木下面
2. 在「運算」分類（綠色系）找「＿−＿」（減法）積木，拖進「重複」的數字空格裡
3. 減號左邊：去「變數」分類找清單「排行榜分數」的**長度**積木（有些版本顯示「項目數量」），拖進去
4. 減號右邊：把「輪次」變數積木拖進去

做完應該是：重複（「排行榜分數」的長度 − 「輪次」）次

### 3-3　內層迴圈裡面：i往前走一格

1. 找「變數＿改變＿」積木，拖進「重複」中間空的地方（**卡進去**，不是接在外面）
2. 第一個空格選「i」，後面填`1`

### 3-4　內層迴圈裡面：比較

1. 在「控制」分類找「如果＿那麼」C型積木，拖到「將i改變1」的下面——**要留在「重複」的容器裡面**，拖的時候看白色外框圈住的是哪一層
2. 在「運算」分類找「＿>＿」積木，拖進「如果」後面的六角形空格
3. 「＿>＿」**左邊**：拖一個「排行榜分數的第＿項」積木進來，裡面的空格放「i」變數積木
4. 「＿>＿」**右邊**：再拖一個「排行榜分數的第＿項」積木進來，裡面的空格放「最大值位置」變數積木

做完應該是：如果「排行榜分數的第i項」＞「排行榜分數的第（最大值位置）項」那麼

右邊很容易做錯：要比的是「最大值位置那一格的**分數**」，不是「最大值位置」這個數字本身。所以右邊一定要套一個「排行榜分數的第＿項」。

### 3-5　如果成立：記住新的位置

1. 在「如果那麼」中間空的地方，放一個「變數＿設為＿」積木
2. 第一個空格選「最大值位置」，後面放「i」變數積木

到這裡，內層「重複」裡面應該長這樣：

- 將「i」改變`1`
- 如果「排行榜分數的第i項」＞「排行榜分數的第（最大值位置）項」那麼
  - 將「最大值位置」設為「i」

### 3-6　交換三步（放在內層迴圈的「下面」）

**注意位置**：交換要等整輪擂台打完才做，所以這三個積木要接在內層「重複」這個**大容器的下面**（容器外面），不是放進容器裡。

1. 「變數＿設為＿」：選「暫存」，後面放「排行榜分數的第＿項」，裡面放「輪次」
2. 在「變數」分類找開頭是「替換」的清單積木（替換排行榜分數的第＿項為＿）：
   - 第一個空格（第幾項）放「輪次」
   - 第二個空格（換成什麼）放「排行榜分數的第＿項」，裡面放「最大值位置」
3. 再拖一個「替換」積木：
   - 第一個空格放「最大值位置」
   - 第二個空格放「暫存」變數積木

三步的順序不能對調，原因可以回去講義第二節看交換動畫。

### ✅ 檢查點1

先按**綠旗**，再按 **s**。看舞台左上角的清單，應該變成：**980、790、650、875、860**

- 對了 → 繼續第四步
- 不對 → 先看下面「常見問題」

## 第四步：外面再包一層迴圈

### 4-1　把「重複」插進去包住

這裡有一個Scratch的小技巧：**把C型積木插進一串積木的中間，它會自動把下面所有積木包進去。**

1. 從「控制」分類再拖一個「重複＿次」積木
2. 放在「將『輪次』設為1」和「將『最大值位置』設為『輪次』」**中間**，放開
3. 檢查：從「將『最大值位置』設為『輪次』」一直到第二個「替換」，應該全部都被新的「重複」包在裡面；「將『輪次』設為1」留在外面最上面

如果包錯了，用 Ctrl+Z 復原再試一次。

### 4-2　外層要重複幾次

1. 在新的「重複」空格裡放「＿−＿」積木
2. 左邊放「排行榜分數」的長度，右邊填`1`

做完應該是：重複（「排行榜分數」的長度 − 1）次。5筆資料排4輪。

### 4-3　每排完一輪，輪次加1

1. 拖一個「變數＿改變＿」積木，選「輪次」，填`1`
2. 放在第二個「替換」的下面——**還在外層「重複」的裡面**，是外層迴圈裡的最後一個積木

### 4-4　排完之後，說出結果

1. 在「外觀」分類找「說出＿」積木（**不要用「說出＿持續...2秒」**，泡泡會自動消失）
2. 接在外層「重複」大容器的**下面**（容器外面）
3. 空格裡放「排行榜分數」這個清單積木本身（在「變數」分類，清單名稱那一塊）

全部做完，整組積木由上到下應該是：

1. 將「輪次」設為`1`
2. 重複（「排行榜分數」的長度 − 1）次
   - 將「最大值位置」設為「輪次」
   - 將「i」設為「輪次」
   - 重複（「排行榜分數」的長度 − 「輪次」）次
     - 將「i」改變`1`
     - 如果「排行榜分數的第i項」＞「排行榜分數的第（最大值位置）項」那麼
       - 將「最大值位置」設為「i」
   - 將「暫存」設為「排行榜分數的第（輪次）項」
   - 替換排行榜分數的第（輪次）項為「排行榜分數的第（最大值位置）項」
   - 替換排行榜分數的第（最大值位置）項為「暫存」
   - 將「輪次」改變`1`
3. 說出「排行榜分數」

### ✅ 檢查點2

先按**綠旗**，再按 **s**。角色應該說出：**980 875 860 790 650**

## 第五步：截圖、下載、重新命名

1. 先按**綠旗**、再按 **s**，等角色說出 980 875 860 790 650
2. 用第二週教過的截圖方法，把**整個舞台區**截下來：要看得到角色的說話泡泡，還有左上角的「排行榜分數」清單。存成PNG或JPG都可以
3. 點選單「檔案→匯出到你的電腦」，會下載一個副檔名`.sb3`的檔案
4. 依照第二週教過的檔名格式重新命名：`班級_座號_姓名_日期排序.sb3`，例如 `108_16_王小明_1019排序.sb3`（日期跟「排序」中間不用底線）

## 第六步：繳交

1. 回到講義頁面，點「前往『列隊行動任務繳交』」連結
2. 依格式填寫班級座號姓名
3. 上傳剛剛重新命名好的`.sb3`檔案，再上傳截圖
4. 送出後系統會立刻自動檢查，馬上顯示一個建議分數給你參考——正式成績要等老師確認公布才算數

## 常見問題

- **按s完全沒反應**：積木可能沒有真的接在「當按下s鍵」下面，是分開散落在旁邊——檢查積木之間有沒有卡緊
- **按s之後清單沒變，本來就是排好的**：你忘了先按綠旗。先按綠旗讓清單變回 790、980、650、875、860，再按s
- **清單裡出現兩個一樣的數字（例如兩個980），有一個分數不見了**：交換的三步順序錯了，或是少了「暫存」那一步——回頭看3-6，一定要先把「排行榜分數的第（輪次）項」存進「暫存」
- **清單完全沒變，或換錯人**：檢查3-4「＞」右邊有沒有套「排行榜分數的第＿項」。如果直接放「最大值位置」，比的就變成「位置的號碼」，不是分數
- **檢查點1的數字很亂，換了好幾次**：交換的三個積木可能被放進了內層「重複」的裡面——它們要在內層容器的下面，等整輪打完才換一次
- **整個跑完，結果跟檢查點1一樣，只有第1名對**：「將『輪次』改變1」沒有放、或放到外層迴圈的外面去了，每一輪都還在排第1名——回頭看4-3
- **外層「重複」只包住了一部分積木**：用 Ctrl+Z 復原，重新照4-1把「重複」插在「將『輪次』設為1」的正下方
- **說出的只有一個數字，不是一整排**：「說出」裡面放的是「排行榜分數的第＿項」，不是清單本身——換成「變數」分類裡寫著「排行榜分數」那一塊
- **找不到「改編」按鈕**：先確認自己有沒有登入帳號，沒登入的話畫面上不會出現這個按鈕
- **改完之後重新整理，東西不見了**：代表你改的是老師的原始專案，不是自己改編後的版本——回到第一步重新操作一次「改編」
- **截圖上傳不了**：只能上傳PNG、JPG、WebP圖片，檔案不能超過8MB。如果截圖存成了別的格式，重新截一次存成PNG
- **截圖裡的泡泡不見了**：「說出」用成了「說出＿持續...2秒」，泡泡自動消失了——換成「說出＿」，重新按綠旗、按s再截一次
- **忘記重新命名就上傳了**：重新整理繳交頁面再填一次、重新上傳正確命名的檔案即可
