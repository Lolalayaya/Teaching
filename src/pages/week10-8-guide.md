# 定位行動・詳細步驟說明

這頁不會出現在網站選單或講義列表裡，是老師給覺得卡關、或時間快來不及的同學看的加強版說明。如果你已經照著講義裡的「操作提示」順利完成，不用特別看這一頁。

**還沒有Scratch帳號、或忘記帳號密碼？** 第4堂講義裡有「開始之前：註冊／登入Scratch帳號」完整說明，先處理好帳號問題再回來這頁繼續。

## 第一步：打開起始專案、變成自己的

1. 在講義頁面找到「定位行動起始專案」的嵌入畫面。如果畫面顯示灰色的破圖示，不用擔心，這是正常的——點畫面下方的「在新視窗開啟」連結，會用新的分頁打開真正的Scratch頁面。
2. 確認自己已經登入Scratch帳號（右上角要看到自己的帳號名稱，不是「登入」兩個字）。
3. 找到專案頁右上角紫色的「切換到程式頁面」按鈕（英文介面是 See inside）並點下去，會進到積木編輯畫面。

   <img class="howto-img" src="../materials/scratch-howto/see-inside.png" alt="Scratch專案頁右上角的紫色按鈕「切換到程式頁面」" loading="lazy">

4. **這時候還不是你自己的專案**，你改的東西沒辦法存檔。要在畫面右上角找一個像「循環箭頭」的小按鈕，滑鼠移過去會顯示「改編」或「Remix」，點下去。
5. 點下去之後，網址列的專案編號會變成一組新的數字——這代表現在是你自己的專案了。之後隨時可以按 Ctrl+S 或選單「檔案→立即儲存」存檔。

## 第二步：看懂專案裡已經有什麼

打開後，你會看到：

- 舞台左上角：清單「排行榜分數」，裡面是由高到低排好的15個分數（990、965、940……655）
- 舞台右邊：七個變數「目標」「名次」「比較次數」「i」「左」「右」「中間」
- 「當綠旗被點擊」：把清單重新放好、把「目標」設成703、「名次」「比較次數」歸零。**這組不用動，也不要刪掉**
- 「當按下 n 鍵」：把「目標」換成800。**這組不用動，也不要刪掉**
- 「當按下 a 鍵」：循序搜尋，已經寫好大半，只差「重複直到」的六角形空格
- 「當按下 b 鍵」：底下空空的，二分搜尋要接在這裡

**⚠️ 清單的15個數字、七個變數的名稱，都不能更改。** 老師評分是拿你的結果跟參考答案逐項比對，被改掉的話系統會比對不出來。

## 第三步：填好循序搜尋的條件（a 鍵）

**⚠️ 條件填好之前不要按 a**，不然迴圈會停不下來。不小心按了的話，按舞台上方的紅色停止鈕。

### 3-1　先放「或」

1. 在左側「運算」分類（綠色系）找「＜＿＞或＜＿＞」積木

   <img class="howto-img" src="../materials/scratch-howto/category-operators.png" alt="點左側綠色的「運算」分類後，積木區會出現「或」「且」「不成立」和比較大小的積木" loading="lazy">

2. 拖進「當按下 a 鍵」底下那個「重複直到」後面的六角形空格

### 3-2　「或」的左邊：找到了

1. 在「運算」分類找「＿＞＿」積木，拖進「或」**左邊**的六角形空格
2. 「＞」左邊：去「變數」分類把「名次」變數積木拖進去
3. 「＞」右邊：打`0`

### 3-3　「或」的右邊：翻完最後一張

1. 在「運算」分類找「＿＝＿」積木，拖進「或」**右邊**的六角形空格
2. 「＝」左邊：把「i」變數積木拖進去
3. 「＝」右邊：去「變數」分類找清單「排行榜分數」的**長度**積木（有些版本顯示「項目數量」），拖進去

做完應該是：

> 重複直到 ＜（「名次」＞ 0）或（「i」＝「排行榜分數」的長度）＞

### ✅ 檢查點1

先按**綠旗**，再按 **a**。看舞台右邊：「名次」是 **13**、「比較次數」是 **13**。

- 對了 → 繼續第四步
- 不對 → 先看下面「常見問題」

## 第四步：做出二分搜尋（b 鍵）

這一步積木比較多，照順序一塊一塊放，每放完一小節就對照一下。

### 4-1　起手式：四個「設為」

接在「當按下 b 鍵」下面，用「變數」分類的「變數＿設為＿」積木：

1. 將「左」設為`1`
2. 將「右」設為「排行榜分數」的長度（後面空格**不要打15**，把清單的長度積木拖進去）
3. 將「名次」設為`0`
4. 將「比較次數」設為`0`

### 4-2　重複直到：找到或範圍空了

1. 從「控制」分類（黃色系）拖一個「重複直到」，接在4-1的四個積木下面
2. 六角形空格裡放「＜＿＞或＜＿＞」
3. 「或」**左邊**：「＿＞＿」，左邊放「名次」，右邊打`0`（跟第三步一樣）
4. 「或」**右邊**：「＿＞＿」，左邊放「**左**」變數，右邊放「**右**」變數

做完應該是：重複直到 ＜（「名次」＞ 0）或（「左」＞「右」）＞

### 4-3　迴圈裡面：算出中間

這是最多層的一塊，**從外往裡**組：

1. 拖一個「變數＿設為＿」**卡進**「重複直到」中間空的地方，第一個空格選「中間」
2. 在「運算」分類**最下面附近**找「絕對值（＿）」積木（前面有一個下拉選單），拖進「設為」後面的空格
3. 點「絕對值」旁邊的**下拉箭頭**，改選「**無條件捨去**」
4. 在「運算」分類找「＿÷＿」，拖進「無條件捨去」的空格
5. 「÷」右邊打`2`
6. 「÷」左邊放「＿＋＿」，加號左邊放「左」、右邊放「右」

做完應該是：將「中間」設為 無條件捨去（（「左」＋「右」）÷ 2）

**檢查方法**：「無條件捨去」要包在**最外面**。如果變成「無條件捨去（左＋右）÷ 2」，就是除以2的動作跑到外面去了，會算出小數。

### 4-4　迴圈裡面：比較次數加1

拖一個「變數＿改變＿」，選「比較次數」、填`1`，接在4-3的「設為」下面（**還在「重複直到」裡面**）。

### 4-5　迴圈裡面：外層的「如果…否則」

1. 在「控制」分類找「如果＿那麼／否則」（有上下兩個開口的那個），接在「將比較次數改變1」下面，**還在「重複直到」裡面**
2. 六角形空格放「＿＝＿」
3. 「＝」左邊：拖「排行榜分數的第＿項」積木，裡面的空格放「**中間**」變數
4. 「＝」右邊：放「目標」變數
5. 「如果」的**上面開口**（那麼）：放「將『名次』設為『中間』」

### 4-6　「否則」裡面：再放一個「如果…否則」

1. 再拖一個「如果＿那麼／否則」，放進外層「如果」的**下面開口**（否則）裡
2. 六角形空格放「＿＞＿」
3. 「＞」**左邊**：放「目標」變數
4. 「＞」**右邊**：拖「排行榜分數的第＿項」，裡面放「中間」
5. 裡層「如果」的**上面開口**：將「右」設為（「中間」− 1）——用「運算」的「＿−＿」
6. 裡層「如果」的**下面開口**：將「左」設為（「中間」＋ 1）——用「運算」的「＿＋＿」

**方向不要放反**：目標比較高 → 分數高的在前面 → 往前找 → 改「**右**」。

全部做完，「當按下 b 鍵」由上到下應該是：

1. 將「左」設為`1`
2. 將「右」設為「排行榜分數」的長度
3. 將「名次」設為`0`
4. 將「比較次數」設為`0`
5. 重複直到 ＜（「名次」＞ 0）或（「左」＞「右」）＞
   - 將「中間」設為 無條件捨去（（「左」＋「右」）÷ 2）
   - 將「比較次數」改變`1`
   - 如果「排行榜分數的第（中間）項」＝「目標」那麼
     - 將「名次」設為「中間」
   - 否則
     - 如果「目標」＞「排行榜分數的第（中間）項」那麼
       - 將「右」設為（「中間」− 1）
     - 否則
       - 將「左」設為（「中間」＋ 1）

### ✅ 檢查點2

先按**綠旗**，再按 **b**。舞台右邊：「名次」是 **13**、「比較次數」是 **4**，「左」「右」「中間」都是13。

## 第五步：截圖、下載、重新命名

1. 先按**綠旗**、再按 **b**
2. 用第二週教過的截圖方法，把**整個舞台區**截下來：要看得到舞台右邊的「名次」和「比較次數」。存成PNG或JPG都可以
3. 點選單「檔案→下載到你的電腦」，會下載一個副檔名`.sb3`的檔案

   <img class="howto-img" src="../materials/scratch-howto/download.png" alt="Scratch編輯器左上角「檔案」選單裡的「下載到你的電腦」" loading="lazy">

4. 依照第二週教過的檔名格式重新命名：`班級_座號_姓名_日期搜尋.sb3`，例如 `108_16_王小明_1102搜尋.sb3`（日期跟「搜尋」中間不用底線）

## 第六步：繳交

1. 回到講義頁面，點「前往『定位行動任務繳交』」連結
2. 依格式填寫班級座號姓名
3. 上傳剛剛重新命名好的`.sb3`檔案，再上傳截圖
4. 送出後系統會立刻自動檢查，馬上顯示一個建議分數給你參考——正式成績要等老師確認公布才算數

## 常見問題

- **按a之後數字一直跳、停不下來**：「重複直到」的條件沒填，或是填錯了永遠不會成立——按紅色停止鈕，回頭看第三步。常見錯誤是「或」用成了「且」：「且」要兩件事**同時**發生才停，找到703的時候i還不是15，就停不下來
- **檢查點1的「名次」是13，但「比較次數」是15**：條件只寫了「i＝長度」，少了「名次＞0」，找到之後沒有停，一路翻到最後——補上「或」的左邊
- **按b之後名次一直是0**：先看「左」「右」最後停在哪。如果「左」跑到比「右」大，通常是方向放反了：目標比較高要改「右」，不是改「左」，回頭看4-6
- **按b之後停不下來**：「重複直到」右邊的條件寫成了「左＝右」或「左＜右」，要是「**左＞右**」；或是「右」的設定少了「− 1」、「左」少了「＋ 1」，範圍永遠縮不完
- **「中間」出現小數（例如7.5）**：「無條件捨去」沒有包在最外面——回頭看4-3。這份榜單15筆剛好每次都整除，所以就算忘了加，結果也可能看起來是對的，請自己檢查積木有沒有照4-3組好
- **下拉選單還停在「絕對值」**：結果可能剛好也對（中間都是正整數），但意思錯了，記得改成「無條件捨去」
- **找不到「無條件捨去」**：它不是一塊獨立的積木，是「絕對值（＿）」積木的下拉選單選項，在「運算」分類比較下面的位置
- **比較次數是5或6，不是4**：通常是比較次數改變1放錯位置（被放進了「如果」裡面，或放到「重複直到」外面）。它要在「重複直到」裡面、「如果」的上面
- **按n之後再按a、b，名次不是0**：n鍵的積木可能被改掉了。名次是0才代表「找不到」
- **找不到「改編」按鈕**：先確認自己有沒有登入帳號，沒登入的話畫面上不會出現這個按鈕
- **改完之後重新整理，東西不見了**：代表你改的是老師的原始專案，不是自己改編後的版本——回到第一步重新操作一次「改編」
- **截圖上傳不了**：只能上傳PNG、JPG、WebP圖片，檔案不能超過8MB。如果截圖存成了別的格式，重新截一次存成PNG
- **忘記重新命名就上傳了**：重新整理繳交頁面再填一次、重新上傳正確命名的檔案即可
