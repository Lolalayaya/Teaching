# 課堂規則與自由時間白名單

本頁公告的是**課堂規則與自由時間白名單**

詳細說明如下，請同學們務必要遵守！

上課先將電腦開機，登入學校 Gmail 後進入 Google Classroom，並點開課程網站。

登入方式：從學校首頁點選**校園雲端**，帳號輸入**學號**，密碼預設為**身分證字號**（第一個字母要大寫）。

## 課堂規則

1. 完成該堂課的作業後，可以自由活動（但僅限下面列出來的網站）。
2. 若無故打斷老師授課，會影響課程進度，並減少大家的自由時間。
3. 上課時竊竊私語，老師將讓你到前面與全班分享你的想法。
4. 發言前請先**舉手**，等老師點名後再發言。
5. 若有問題，請舉手詢問老師。
6. 上課前在教室外整隊，等待老師同意後全班**安靜脫鞋**後進入教室。
7. 請依照座號入座，如果設備有問題，需**先告知老師**後，才能更換座位。
8. 下課後，請將網頁登出並關機（Win鍵 → 電源鍵 → 關機），並將使用的設備及椅子**放回原位**，確保教室整潔，沒有遺留的垃圾後才可以離開。
9. 課堂上**禁止趴下**休息。如因身體不適需要休息，請提前告知老師。
10. 上課期間禁止離開教室，如果真的急需上廁所請舉手詢問老師。
11. 電腦教室禁止飲食，如因生病不得不喝水或吃藥請告知老師後到教室外處理。

## 自由時間可以做什麼

完成當天的作業後可以自由活動，但僅限於下面列出的**學習、教學類**網站：

| 分類 | 網站 |
| --- | --- |
| 程式設計 | [Scratch](https://scratch.mit.edu/)、[Code.org](https://code.org/)、[Blockly Games](https://blockly.games/) |
| 綜合學習 | [均一教育平台](https://www.junyiacademy.org/)、[教育部因材網](https://adl.edu.tw/)、[PaGamO](https://www.pagamo.org/) |
| 打字練習 | [TypingClub](https://www.typingclub.com/)、[10FastFingers](https://10fastfingers.com/)、[Typing.tw](https://typing.tw/)、[花蓮縣打字練習網](https://contest.hlc.edu.tw/typing/)、[快打高手](http://www.kiec.kh.edu.tw/typing/index.asp)、[校園打字Game](http://tgame.eduweb.com.tw/index.php)、[BBC Bitesize 英打教學](https://www.bbc.co.uk/bitesize/topics/zf2f9j6/articles/z3c6tfr) |
| 運算思維 | [運算思維小遊戲](https://padlet.com/lola91310_2/padlet-s0236z31enybsb4mkrg3) |

**不可以**看影片、玩非教學類的遊戲、使用社群或聊天軟體。

不確定某個網站算不算，請先詢問老師，若老師認為是適合的，也有可能會更新到上面白名單中。

如果被老師發現偷偷使用白名單以外、未經老師同意的網站：第一次是口頭警告；第二次起，不只會暫停一段時間的自由時間資格，還會列入「上課表現」的扣分項目。
