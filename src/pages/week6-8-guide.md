# 掃描行動・詳細步驟說明

這頁不會出現在網站選單或講義列表裡，是老師給覺得卡關、或時間快來不及的同學看的加強版說明。如果你已經照著講義裡的「操作提示」順利完成，不用特別看這一頁。

**還沒有Scratch帳號、或忘記帳號密碼？** 第4堂講義裡有「開始之前：註冊／登入Scratch帳號」完整說明，先處理好帳號問題再回來這頁繼續。

## 第一步：打開起始專案、變成自己的

1. 在講義頁面找到「掃描行動起始專案」的嵌入畫面。如果畫面顯示灰色的破圖示，不用擔心，這是正常的——點畫面下方的「在新視窗開啟」連結，會用新的分頁打開真正的Scratch頁面。
2. 確認自己已經登入Scratch帳號（右上角要看到自己的帳號名稱，不是「登入」兩個字）——還沒登入的話，第4堂講義裡有註冊/登入的詳細步驟。
3. 找到「進去看看」（英文有時顯示 See inside）按鈕並點下去，會進到積木編輯畫面。
4. **這時候還不是你自己的專案**，你改的東西沒辦法存檔。要在畫面右上角找一個像「循環箭頭」的小按鈕，滑鼠移過去會顯示「改編」或「Remix」，點下去。
5. 點下去之後，網址列的專案編號會變成一組新的數字——這代表現在是你自己的專案了，改的東西才存得住。之後隨時可以按 Ctrl+S 或選單「檔案→立即儲存」存檔。

## 第二步：看懂專案裡已經有什麼

打開後，你會看到：

- 一個清單，名字叫「排行榜分數」，裡面已經放好5筆分數：870、650、785、990、920（順序故意是亂的，不是由小到大或由大到小）
- 兩個變數：「目前最大值」跟`i`，數值目前都是0——這是正常的，等一下你自己的積木會改變它們
- 一個空空的積木，開頭是「當按下 s 鍵」，底下還沒有接任何東西——這就是你今天要蓋積木的地方

**⚠️ 這個清單的5個數字、跟這兩個變數的名稱，都不能更改。** 老師評分是拿你的結果跟參考答案逐項比對，清單內容或變數名稱被改掉，系統會比對不出來，不會有分數。

## 第三步：在「當按下 s 鍵」下面，蓋出「找最大值」的積木塔

這一步是今天的重點，積木會疊好幾層，照順序一步一步來，不要跳著做。

### 3-1　先處理「起手式」：i設為1、最大值先抓第1筆

1. 在左側積木分類找「變數」分類（橘色系，清單相關的積木也放在這裡），找到「將＿設為＿」這個積木
2. 拖到「當按下 s 鍵」積木下面接起來，第一個空格的下拉選單選`i`，後面空格打`1`
3. 再拖一個「將＿設為＿」積木，接在剛剛那個下面，第一個空格選「目前最大值」
4. 這次後面的空格**不要直接打數字**，要去「變數」分類找「排行榜分數的第＿項」這個積木（清單專用的積木），拖進「將目前最大值設為＿」的空格裡，裡面的數字填`1`
5. 做完這兩步，你的積木應該是：
   - 將`i`設為`1`
   - 將「目前最大值」設為「排行榜分數的第1項」

### 3-2　做一個「重複執行4次」的容器

1. 在左側「控制」分類（黃色系）找「重複執行＿次」這個C型積木（中間是空的，可以把其他積木放進去）
2. 拖到前面兩個積木下面接起來，數字填`4`（**不是5**——還記得上週「n-1次」的規則嗎？清單有5筆，所以重複4次）

### 3-3　容器裡面，第一層：讓`i`往前走一格

1. 回到「變數」分類，找「將＿改變＿」這個積木
2. 把它拖進「重複執行4次」中間空的地方（會卡進去，不是接在外面）
3. 第一個空格選`i`，後面填`1`

### 3-4　容器裡面，第二層：比較、有需要才更新

1. 在「控制」分類找「如果＿那麼」這個C型積木
2. 拖到「將i改變1」的下面——**注意位置：要讓它還留在「重複執行4次」的大容器裡面**，不是跑到外面去了（拖的時候Scratch會用白色外框提示你現在卡進哪一層，拖之前先確認外框圈住的是重複執行的範圍）
3. 在「運算」分類（綠色系）找「＿>＿」這個積木，拖進「如果」後面的六角形空格裡
4. 「＿>＿」左邊空格：去「變數」分類拖一個「排行榜分數的第＿項」積木進來，裡面原本填數字的地方，改成直接把`i`這個變數積木拖進去（不要打數字，要放變數本身）
5. 「＿>＿」右邊空格：直接把「目前最大值」這個變數積木拖進去
6. 這樣「如果」後面應該會變成：如果「排行榜分數的第i項」＞「目前最大值」那麼

### 3-5　如果成立，更新最大值

1. 在「如果那麼」中間空的地方（C型積木裡面），放一個「將＿設為＿」積木
2. 第一個空格選「目前最大值」
3. 後面空格一樣放「排行榜分數的第＿項」積木，裡面放`i`這個變數（跟3-4第4點做法一樣，再做一次）

到這裡，「重複執行4次」裡面應該長這樣（由外到內）：

- 將`i`改變`1`
- 如果「排行榜分數的第i項」＞「目前最大值」那麼
  - 將「目前最大值」設為「排行榜分數的第i項」

### 3-6　跳出重複執行，說出結果

1. 確認你接下來要放的積木，是接在「重複執行4次」這個**大容器的下面**（容器外面），不是容器裡面——這一步容易手滑接錯層，建議拖的時候放慢一點看清楚白色外框
2. 在「外觀」分類找「說＿」這個積木（**不要用「說＿...2秒」，泡泡會自動消失，不方便自己確認結果**）
3. 在「運算」分類找「接合＿和＿」這個積木，拖進「說」的空格裡
4. 前段空格打文字「最大值是：」
5. 後段空格放「目前最大值」這個變數積木

全部做完，整組積木由上到下應該是：

1. 將`i`設為`1`
2. 將「目前最大值」設為「排行榜分數的第1項」
3. 重複執行`4`次
   - 將`i`改變`1`
   - 如果「排行榜分數的第i項」＞「目前最大值」那麼
     - 將「目前最大值」設為「排行榜分數的第i項」
4. 說「接合『最大值是：』和『目前最大值』」

## 第四步：測試

1. 按鍵盤上的 **s** 鍵
2. 畫面應該要說出「最大值是：990」——如果說出別的數字，或完全沒反應，回頭檢查上面哪一步的積木位置/層次不對（常見錯誤見下面「常見問題」）
3. 可以多按幾次s鍵確認每次結果都一樣是990（積木本身不會因為按多次而壞掉）

## 第五步：下載、重新命名

1. 點選單「檔案→匯出到你的電腦」，會下載一個副檔名`.sb3`的檔案
2. 依照週2教過的檔名格式重新命名：`班級_座號_姓名_日期迴圈.sb3`，例如 `108_16_王小明_1012迴圈.sb3`（日期跟「迴圈」中間不用底線）

## 第六步：繳交

1. 回到講義頁面，點「前往『掃描行動任務繳交』」連結
2. 依格式填寫班級座號姓名
3. 上傳剛剛重新命名好的`.sb3`檔案
4. 送出後系統會立刻自動檢查，馬上顯示一個建議分數給你參考——正式成績要等老師確認公布才算數

## 常見問題

- **按s鍵完全沒反應**：積木可能沒有真的接在「當按下s鍵」下面，是分開散落在旁邊——檢查積木跟積木之間有沒有「卡」緊（接起來的積木中間不會有縫隙）
- **說出的數字一直是870（第一筆），完全沒變過**：通常是「如果」裡面的比較式寫反了，或是比較式裡面的`i`忘記放變數、還是寫死的數字1——回頭看3-4，確認左邊是「排行榜分數的第i項」（`i`是變數不是數字）
- **說出的數字變成650或785，不是990**：代表迴圈提早停了，或是「如果」判斷邏輯哪裡反了——檢查「重複執行」次數是不是真的填4，`i`有沒有每輪都真的+1
- **說出的東西是空白或是「undefined」之類的字**：通常是「接合」積木裡有一格忘記放東西，或是放錯格子——回頭看3-6
- **積木明明接好了，但「如果」那一塊看起來沒有跟著重複執行一起動**：代表「如果」積木其實卡在重複執行的外面，不是裡面——拖回重複執行的C型容器中間重新放一次
- **找不到「改編」按鈕**：先確認自己有沒有登入帳號，沒登入的話畫面上不會出現這個按鈕
- **改完之後重新整理，東西不見了**：代表你改的是老師的原始專案，不是自己改編後的版本——回到第一步重新操作一次「改編」
- **忘記重新命名就上傳了**：重新整理繳交頁面再填一次表單、重新上傳正確命名的檔案即可
