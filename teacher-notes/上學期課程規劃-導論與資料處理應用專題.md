# 上學期課程規劃：導論＋資料處理應用專題（七年級）

內部教學用，不發布到網站上。這份是把課本預設進度**重新排序**後的規劃，課本內容僅供備課參考，實際教學不必照課本順序（七年級只有一位老師任教，不需與其他班對齊進度，只要一整年內涵蓋課綱內容即可）。

## 為什麼要重排

課本原本的章節順序是「導論 → 基礎程式設計(Scratch) → 資料處理應用專題」，但：

- Scratch 下學期還會繼續教，希望這學期的 Scratch 段落能直接接到下學期，避免中間被資料處理應用專題插隊打斷。
- 決定把順序改成：**導論 → 資料處理應用專題（含完整教H-IV-1/2/3） → Scratch（整段移到下學期）**。

## 重要限制

- **不使用課本習作**：全部練習/評量改用網站自製的互動頁面，理由見 `feedback_no_workbook` 記憶。
- **資訊課一週1節**。
- **段考不考筆試，但每次段考都要有成績**，因此每個段考時間點前後要有一個「做完的東西」可以評分，不能剛好卡在專題做一半。
- 三次段考實際日期：**10/13、10/14**（約第7節課附近）／**11/26、11/27**（約第13節課附近）／**1/19、1/20**（約第21節課附近，接近學期末）。

## 整體專題構想

把「H-IV-1/2/3數位公民議題」跟「T-IV-1資料處理應用專題」合併成一個貫穿式專題：**學生分組挑一個主題（個資保護／資訊安全／資訊科技合理使用原則，每組任選），從摘要資料、調查數據、統計分析，最後做出一份宣導用的四格漫畫**。工具學習（Google文件/表單/試算表/Canva）都是為了完成這個真實產出而學，不是為了學軟體操作而學。

資料來源採**混合方式**：主力數據用政府/反詐騙網站現成統計（乾淨、有公信力，可挑跟國中生相關的類型，如遊戲帳號/交友軟體/虛擬貨幣詐騙），另外加一份全班用Google表單當場填寫的輕量匿名小調查，增加「這是我們班的問題」的在地感。

AI協作嵌入摘要階段（NotebookLM，餵資料生成摘要，比一般生成式AI更適合初次練習「跟AI協作」，且風險較低），Canva設計階段若用AI生成配圖，可順勢帶出「AI生成素材算不算自己的創作」的資訊倫理討論。

## 導論（第1~1.5堂）詳細流程

目標：學生能舉例說明資訊科技如何改變食衣住行育樂；理解「發現問題→選對工具→解決問題」的思考模式；預告接下來的資料處理應用專題；知道之後還有議題會再深入（4個快速預告＋3個之後有專門漫畫課程）。

### 第1堂（45分鐘）

| 時間 | 內容 | 備註 |
| --- | --- | --- |
| 0-2min | 收心＋今天主題預告 | |
| 2-8min | 開場鉤子影片（彈性5-9分鐘） | 影片人選待確認，長度確定後微調此段時間 |
| 8-10min | 揭示主軸問題「科技怎麼解決生活中的麻煩？」，說明等一下要「猜一猜」 | |
| 10-34min（24分鐘，6個例子×4分鐘） | 食衣住行育樂六連發：老師講「過去的麻煩」→舉手猜「現在怎麼解決」→公布（App點餐/AR試穿/IoT住宅/輔助駕駛/線上學習/VR遊戲）→追問「你自己有沒有用過類似的？」 | 用猜的方式取代單向講述，多留時間讓學生分享自己的生活經驗 |
| 34-40min | 收斂成一句話：「這6個例子都是同一個公式——有人發現問題，選了適合的工具去解決」 | |
| 40-45min | 拋出開放性鉤子收尾：「你們覺得學校/班上有沒有什麼問題，之後也許可以用資訊科技解決？」（不用現在回答，帶到第二堂） | |

### 第1.5堂（第2堂前22.5分鐘，後半接「分組選主題」）

| 時間 | 內容 | 備註 |
| --- | --- | --- |
| 0-12min（4個議題×3分鐘） | 快速預告1-2剩下四個議題：資訊倫理（糗事亂講）、資訊科技與相關法律（動漫鑰匙圈販售）、媒體與資訊科技相關議題（FB/IG/YouTube/Netflix）、常見資訊產業（硬體/軟體/網通/系統整合） | 各用一個生活案例小故事帶，可順便問「這樣做OK嗎？」讓學生舉手表態 |
| 12-16min | 特別預告：「個資保護、資訊安全、資訊科技怎麼合理使用，這三個之後會有專門課程，用漫畫方式帶大家認識」 | 製造期待感，避免跟後面2堂重複 |
| 16-22.5min | 正式啟下：預告資料處理應用專題（Google文件寫企劃→表單做調查→試算表整理數據→Canva設計海報和漫畫，最後做出真的能拿去宣導的作品） | 收尾複誦：「遇到問題，先想清楚要選哪個工具」 |
