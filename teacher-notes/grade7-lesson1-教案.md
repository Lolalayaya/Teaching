# 第一堂課教案（45分鐘）

內部教學用，不發布到網站上。學生版對應內容在 [src/content/lectures/unit01-intro.md](../src/content/lectures/unit01-intro.md)。

**暫定全年級通用**：這份講義跟密室逃脫目前不分年級，7、8、9年級的第一堂課都用同一份內容（網站上已移除 `grades` 篩選，選任何班級都會看到）。之後如果要依年級拆開不同內容，再回來把 `grades` 欄位加回去、另外拆檔案即可。

- [ ] **帳號情境差異**：下面「帳號密碼」待確認事項是以「發新帳密」為前提寫的，這只適用於**新生（7年級）**。8、9年級是舊生，通常沿用去年的帳號，不需要重新發放——對這兩個年級上課時，這段可以直接改成「提醒大家用原本的帳號密碼登入」，不用照教案原文照講。

## 待確認事項（開學前務必確認）

- [ ] **帳號密碼**：確認資訊組是否已經設定好本學期學生的新帳密，並取得發放用的清單／貼紙。如果開學當天還沒設定好，課堂流程要跳過「登入帳號」段落，改成口頭說明「帳號之後會另外發」，不要卡在這裡浪費時間。
- [ ] **電腦教室代號**：確認這堂課實際使用凱風樓4F 電腦教室1／2／3 中的哪一間，填入教案與學生講義。
- [ ] **評分比例**：確認學校本學期是否要求段考。若不用段考，採用「作業70%+上課表現30%」（已寫入 grades.md）；若要段考，需另外確認統一配分比例並更新 grades.md。

## 教學目標

- 學生能說出電腦教室的使用規則與班訓「可以輕鬆，不可以隨便」
- 學生能成功登入學校帳號（若帳密已備妥）
- 學生能完成密室逃脫的基本操作關卡（鍵盤、滑鼠、視窗、中英切換、快捷鍵、副檔名）
- 學生能說出二進位轉十進位的換算方法，並套用在密室逃脫第8關
- 學生能說出凱薩加密的解密方法（位移量往前移），並套用在密室逃脫第10關
- 學生知道自由時間的範圍（白名單）與下課找老師的方式

## 教材／前置準備

- 確認每台電腦可以開啟 `/escape-room/` 且小畫家（mspaint）可用（第11關需要滴管工具）
- 投影片或黑板寫下今天的網址，方便學生輸入
- 手邊留一份 [escape-room.config.json](../src/content/escape-room.config.json) 的關卡與答案，方便巡場時快速核對卡關學生的答案

## 詳細流程

| 時間 | 段落 | 內容與提醒 |
| --- | --- | --- |
| 0–5 min | 開場 | 老師自我介紹、學期概況一句話帶過。拋出鉤子：「資訊教室被鎖住了，今天要靠大家自己解鎖」。 |
| 5–8 min | 帳號登入 | **視待確認事項而定。** 帳密已備妥：發放／公布帳密，帶學生登入一次。帳密未備妥：口頭說明之後會另外發，直接跳過。 |
| 8–15 min | 二進位 + 凱薩加密教學，以及玩法說明 | 黑板示範二進位轉十進位的算法（見學生講義「六、二進位與十進位換算」的例子：`01110110` = 118），再示範凱薩加密的解密方式（見學生講義「七、凱薩加密解密方法」，位移量往前移、字母表要繞回頭、標點空格不動）。接著說明密室逃脫規則：單機作答、自己的進度、卡關舉手、不能用手機查答案。 |
| 15–33 min | 個人闖關（主體） | 學生各自電腦解關，老師巡場排除障礙。重點盯三處：**第8關**（二進位換算，剛教完可能還不熟）、**第10關**（凱薩加密解密，位移方向跟繞回頭容易搞混）、**第11關**（要開小畫家滴管工具查 Hex 色碼，對很多學生是新操作，示範一次給卡住的人看）。 |
| 33–40 min | 收斂 + 班規揭曉 | 對答案，揭曉班訓「可以輕鬆，不可以隨便」。順勢帶出教室 11 條規則（見學生講義「二、電腦教室使用規則」），以及自由時間白名單（只能玩教學／學習類網站）。 |
| 40–45 min | 收尾 | 說明評分方式（作業70%+上課表現30%，待確認是否有段考）、預告下次上課內容、提醒下課想問問題可以到教師辦公室1（凱風樓2樓，分機605）找曾老師。 |

## 提早解完的學生

第一堂課不特別安排延伸任務，提早解完就自由活動（自由時間白名單同上）。

## 自由時間白名單（已寫入學生講義）

允許：
- 程式設計：Scratch、Code.org、Blockly Games
- 綜合學習：均一教育平台、教育部因材網、PaGamO（可用教育雲端帳號單一簽入）
- 打字練習：TypingClub（typingclub.com）、10FastFingers、Typing.tw、花蓮縣打字練習網（contest.hlc.edu.tw/typing）、快打高手（kiec.kh.edu.tw/typing）、校園打字Game（tgame.eduweb.com.tw）、BBC Bitesize 英打教學

完整超連結已經寫在學生講義的白名單表格裡，這裡只列名稱方便你對照。

不允許：影片、非教學類遊戲、社群／聊天軟體。不確定的網站，學生應該舉手問，而不是自己判斷——這點在課堂上要口頭強調一次。

**違規處理（已寫入學生講義）**：第一次口頭警告；第二次起暫停一段時間的自由時間資格，並列入「上課表現」扣分。巡場時發現學生偷用非白名單網站，直接依這個標準處理，不用臨場另外判斷寬嚴。

因材網、PaGamO 這類支援教育雲端帳號單一簽入的平台，如果學生帳密已經開通，登入門檻最低，可以優先推薦。

## 已知卡關熱點（來自密室逃脫關卡設計）

- 第 4-3 關：大小寫嚴格比對（`text-nopunct-casesensitive`），學生可能因為多打標點或空格而卡住，提醒他們只需要文字本身。
- 第 8-2 關：ASCII 對照表已內建在頁面上，不用自己算，提醒學生往下滑找表格。
- 第 10-1／10-2 關：老師生日月份 + 凱撒密碼位移解密，是唯一需要老師背景知識的題目，巡場時可以直接口頭提示月份。
- 第 11 關：滴管工具在小畫家的「常用」頁籤裡，選取後點一下要取色的表情符號，再開「編輯顏色」看 Hex 值。
